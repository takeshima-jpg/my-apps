# Claude Code 手順書：議事録→OS振り分け（inbox triage）

竹嶋さんが「inboxを振り分けて」と言ったら、この手順で処理する。
これはスクリプトではなく**あなた（Claude Code）が読解して行う作業**。CLAUDE.mdの家訓を継承する。

## 入力
- `inbox/` フォルダ内のテキスト（打合せメモ・文字起こし・箇条書き。形式は不定）
- ファイル名に日付があればその日付、なければ竹嶋さんに1問だけ確認

## 出力
`outputs/triage-YYYY-MM-DD.md` を1ファイル作成。以下の4セクション構成。
**該当が無いセクションは「該当なし」と明記**（勝手に創作して埋めない）。

### ① ヒトメモ更新（AI更新読込に貼る用）
登場人物ごとに、ヒトメモのAI更新形式で出力：
```
### （姓または登録名に含まれる表記）
lastContactDate: YYYY-MM-DD
changeLog:
- 打合せ｜（その人の発言・決定・変化を1行に圧縮。複数あれば行を分ける）
```
- 発言の役割像・関係変化があれば changeLog に。プロフィール欄（経歴等）は**議事録からは更新しない**（調査ではなく接点記録のため）
- Top10外の人物も接点事実としては記録してよい（briefと違い、ヒトメモは記録が仕事）

### ② Shotタスク候補
「誰かがやると決まったこと・竹嶋さんの宿題」を箇条書き：
```
・（タスク名）｜期日：（明言があれば。なければ「期日未定」）｜出典：（発言の要旨）
```
- **決定済みのみ**。提案・アイデア段階のものは④へ
- 竹嶋さん以外の宿題は「（担当：◯◯）」を付ける（Shotに入れるかは本人判断）

### ③ Project OSシート追記行（TSV）
既存プロジェクト（3AHD2030・JSS承継等）に紐づくイベント・決定・分岐があれば、
該当プロジェクトのシート列構成（ID/テーマ/種別/期日/状態/イベント/担当/対象/施策/ゴール/結果）に
合わせたTSV行を出力。IDは空欄（シート側で採番）。種別は 空欄=イベント/分岐/制約 を内容で判断。

### ④ Reflectログ候補
意思決定・気づき・問いに当たる発言を箇条書き（原文の言葉を残す）。
Lectica実験に関する言及があれば「→ 壁打ち/振り返りチャットへ」と付記。

## ルール
- 発言者が不明な内容は「発言者未確認」と明記。推測で人名を当てない
- 竹嶋さんの言葉を残す。経営用語で言い換えない
- 出力後、inboxの元ファイルは `inbox/processed/` へ移動
- 処理結果はチャットで3行以内に要約報告（①N名 ②N件 ③N行 ④N件）
- **どのOSにも自動書き込みしない**。出力はすべて「貼り付け待ち」の形（人が確認して反映する）

## 運用フロー（竹嶋さん側）
1. 会議メモを `inbox/` に保存（ファイル名例：`2026-07-11-幹部会.txt`）
2. Claude Codeに「inboxを振り分けて」
3. triage-*.md を見て、①をヒトメモAI更新読込へ、②をShotへ、③をシートへ、④をReflectへ反映
