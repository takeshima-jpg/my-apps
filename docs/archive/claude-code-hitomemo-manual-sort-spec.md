## 前提
- 関係ステージ（記録のみ/つながり/信頼を深める段階/経営パートナー）＋🤝稼働＋家族カテゴリ(personType=family)は
  実装済みの想定。まだ「家族カテゴリ分離＋並び替え」（claude-code-hitomemo-family-sort-spec.md）が
  未実装なら、それも含めてこの依頼書で一括対応してよい。
- 変更対象：hitomemo/index.html のみ。データ・保存ロジックは無改変（表示制御と並び替えのみ）。

## 1. 一覧の並べ替え機能
一覧画面上部に並べ替えセレクトを追加。並べ替えキー：
- 関係ステージ順（経営パートナー→信頼を深める段階→つながり→記録のみ）※既定
- 最終接触日（新しい順／古い順）
- 名前（あいうえお順）
- 🤝稼働中を上に
- 更新日（新しい順）

選択状態は localStorage に保存し次回も維持。

## 2. カテゴリ別の表示とグルーピング
一覧を関係ステージ（＋家族）でグルーピング表示し、**セクション単位で折りたたみ**できるようにする：
- グループ：経営パートナー / 信頼を深める段階 / つながり / 記録のみ / 家族
- 各グループの見出しに件数を表示し、見出しクリックで開閉（`<details>` またはトグル）。
- **「記録のみ」と「家族」は既定で閉じた状態**にする（数が多く普段は畳んでおきたいため）。
  他グループ（つながり／信頼を深める段階／経営パートナー）は既定で開いた状態。
- 各グループの開閉状態も localStorage に保存し次回に復元。
- 並べ替え（上記1）は各グループ内の並び順に適用する。

## 3. フィルタ（任意・あれば便利）
上部に表示切替：「すべて / パートナー形成のみ / 家族のみ」。難しければグルーピング＋折りたたみだけでよい。

## 4. データ保護
- personType 未設定は 'partner' 扱い（家族グループには入らない）。
- stage 未設定や旧値が入っていてもエラーにせず、判定できないものは「その他/未分類」グループにまとめて表示。

## 検証
- esbuild --jsx=transform で構文検証
- 並べ替え各キーが正しく動作し、選択が保存・復元される
- ステージごとにグルーピングされ、記録のみ・家族が既定で閉じている
- 見出しクリックで開閉でき、開閉状態が保存・復元される
- 既存人物（personType/stage未設定）が消えずに表示される（未分類グループ等）
- モバイル幅で崩れない
