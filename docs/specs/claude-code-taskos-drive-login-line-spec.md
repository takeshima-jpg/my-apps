## §1 経緯
- Task OS は、開いたときに Drive と同期する（バックアップ・受信箱の取り込み・実験の Shot）。Google のログイン（`gdrive_token_taskos`）は約1時間で切れる
- 切れた状態で開くと、自動の同期は 401 で止まり、**画面には何も出ない**。`gdAutoSync` の 401 の所（3330 付近）は `gdClear(); gdSetStatus('ok');` で、`gdSetStatus('ok')` がボタンの字を「☁️ GDrive同期」にしてしまう（つながっていないのに、つながっているように見える）。本人が気づかないまま、バックアップも受信箱の取り込みも止まる
- 実際に起きたこと：11/18・11/19・11/20 の朝の同期がこれで止まった（バックアップの `taskosSyncTiming` で `steps` が空の回）。11/19 朝に置いた受信箱が入ったのは 11/21 0時台。11/21 21:44 の後は 11/24 午後まで一度も同期していない
- 本人決定（11/24）：ログインが切れているときだけ、ホームの一番上に1行出す

## §2 直すこと（`task-os/index.html`）
1. **知らせの1行**：Drive につながっていないとき（`gdToken` が無いとき）だけ、ホーム（HOME の画面）の一番上＝VISION のすぐ下・「今日やること」の上に、1行出す
   - 文：**「☁️ Drive につながっていません（押すとつなぎ直します）」**
   - 行ぜんぶが押せる（ボタン）。押すと `gdConnect()`（今の「☁️ GDrive接続」と同じ動き。Google の画面から戻ると、今までどおり自動で同期が走る）
   - 色：文字 `#8a5300`・背景 `#fbf0dc`（ソーシャルユニバースの見直しの帯と同じ黄土色）。**赤・オレンジにしない。「⚠」を付けない。点滅・アニメーションなし**。高さは押しやすく（40px 以上）、角は周りのカードに合わせる
   - つながっているとき（`gdToken` があるとき）・同期中は**何も出さない**（場所も空けない）
   - 「最後に同期した日時」「◯日つながっていません」などの数字・日数は出さない
2. **出し入れのしかた**：ホームの中身の描き直し（`renderHome()`）に頼らず、専用の要素を1つ置いて、`gdToken` が変わる所で出し入れする（`gdUpdateBtn()` の中で一緒に切り替えるのがよい）。こうすると、`gdClear()`（同期の 401・依頼書17 の裏の書き込みの 401）・`gdHandleRedirect()` の後・起動時のどれでも同じに動く。`renderHome()` で描き直しても消えない・二重に出ないこと
3. **ボタンの字の直し**：`gdAutoSync` の 401 の所で、`gdClear()` の後に `gdSetStatus('ok')` を呼ばない（または `gdSetStatus` の `ok` を、`gdToken` が無いときは「☁️ GDrive接続」にする）。401 の後、左のボタンの字が「☁️ GDrive接続」になっていること
4. 手で「同期」を押して 401 だったときの今の動き（アラート「GDriveの認証が切れました。再接続してください。」→ `gdConnect()`）は変えない
5. 一度も Drive につないだことが無い状態（`gdrive_token_taskos` が無い）でも、同じ1行を出す（本人はいつも Drive につないで使うため、分けない）
6. ホーム以外の画面（Shot・Project など）には出さない

## §3 触らないもの
- 同期の中身・順番、受信箱、バックアップ
- Google のログインのしかた（`gdConnect` の中身・権限の範囲）
- ほかの OS（ヒトメモなどにも Drive のログインがあるが、今回は Task OS だけ）
- スマホ幅の確認は不要（PC だけ）

設計の根拠（UI心理学）：フォン・レストルフ効果（切れているときだけ、1つだけ違う色の行を出す）／フィッツの法則（行ぜんぶを押せるようにして、一番上に置く）／ヒックの法則（することは「押す」の1つだけ）／損失回避（バックアップと取り込みが止まっていることに、その場で気づける）／ヤコブの法則（押した後は今の「GDrive接続」と同じ流れ）。催促にしない：つながっているときは出さず、数字・日数・赤を使わない

## §4 確かめること（Code 自身の確認）
1. `gdrive_token_taskos` に切れたトークンを入れて開く → 自動の同期が 401 になり、ホームの一番上に黄土色の1行が出る。左のボタンの字が「☁️ GDrive接続」。アラートは出ない
2. その1行を押す → Google のログインへ進む（`gdConnect()` が呼ばれる）
3. 正しいトークンで開く・同期が通る → 1行が出ない。場所も空かない
4. `gdrive_token_taskos` が無い状態で開く → 1行が出る
5. 1行が出ている状態で `renderHome()` が何度走っても、1行が1つだけ出ている。ホーム以外の画面では出ない
6. 依頼書17 の裏の書き込みで 401 → 1行が出る
7. 手で「同期」を押して 401 → 今までどおりアラートの後に `gdConnect()`
8. PC 幅（1280px）で崩れない。色が `#8a5300`／`#fbf0dc` で、赤・オレンジ・「⚠」が無い
