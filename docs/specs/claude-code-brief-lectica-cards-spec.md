## §1 目的と経緯
- 11/9 本人決定：毎朝のブリーフの「✦ 今日の実験」に、Lectica 壁打ちと同じ「実験の説明3行（力・広がり方・示唆）」を載せる。11/10 分から daily-brief.json の次の2か所に3つの欄が入っている
  - `lectica_daily_practice`（今日の実験）
  - `lectica_next`（明日の予告）
  - 欄：`power`＝力（例「視点を調整する力（Perspective coordination）」）／`spread`＝広がり方／`insight`＝示唆（どれも文字列）
- 今の TOP のカードは「✦ 明日の予告」（`lectica_next`）の1枚だけ。今日の実験は本文の「① 内省・学び」の中にしかない
- 11/10 本人決定：**TOP に「✦ 今日の実験」のカードを足して2枚にし、どちらにも3行を出す**（朝は今日の実験、夜は明日の予告が目に入るように）
- 11/10 本人決定（続き）：3行が増えてカードが長くなるので、**TOP のカードはお題・説明3行・合図だけを見せ、やり方サンプルと「なぜ今」は「やり方を見る」に畳む。明日の予告のカードは18時まで畳んでおく**（§3-2・§3-3）。本文の「✦ 今日の実験」「✦ 明日の予告」には全文が残る

設計の根拠（UI心理学）：ミラーの法則（一度に目に入る行をお題・3行・合図に絞る）／ヒックの法則（朝に選ぶのは今日の実験だけにする）／フォン・レストルフ効果（合図＝実験の引き金を畳まずに残して目立たせる）

## §2 「✦ 今日の実験」のカードを足す（`brief-viewer/index.html`）
- 毎朝タブのときだけ、`data.lectica_daily_practice` も `render()` に渡す（今の `lectica_next` と同じ渡し方。309 行付近）
- 並び：鮮度の帯・図つきのページの入口・`.bv-meta` の下に、**「✦ 今日の実験」→「✦ 明日の予告」**の順
- 作りは今の `lectinCardHTML()` を共通にして、見出しの文字だけ変える（例：引数で「今日の実験」／「明日の予告」を渡す）。見出しは「✦ 今日の実験（11/10 火）」の形。日付は `date` から
- 今日の実験のデータの欄名は、明日の予告と違うものがある。両方を読む：
  - 実験ID：`experimentId` か `selectedExperimentId`
  - 題名：`title` か `selectedExperimentTitle`
  - そのほか（`samples`・`whyNow`・`signal`・`focusQuestion`・`relatedExperimentId`／`relatedExperimentTitle`・`date`）は同じ名前
- 実験ID も題名も無いときはカードを出さない（今と同じ）。`date` が今日より前なら、明日の予告のカードと同じく薄く出す（今の `bv-lectin-past`）
- 今日の実験のカードも `<details open>`（最初から開いている）
- 本文の「## ✦ 今日の実験」はそのまま残す（明日の予告と同じく二重に出るのは受け入れる）

## §3 説明3行（2枚のカードとも）
- 置き場所：「お題」の行の下・「やり方サンプル」の上。「（重点の問い：…）」の行があるときはその下
- 1行ずつ：
  - 見出し「力」→ `power`
  - 見出し「広がり方」→ `spread`
  - 見出し「示唆」→ `insight`
- 見出しの形は、今の「お題」「なぜ今」「合図」と同じ左の見出し（`.bv-lx-row` ＋ `.bv-lx-k`）
- 欄が無い・空の文字のときは、**その行ごと出さない**（3つのうち一部だけある日は、ある行だけ出す）。11/9 までのデータでは3行とも出ない
- 9/21 以前の旧形式（`samples` が無い）でも、欄があれば同じ位置（お題の下）に出す
- **見出しの幅をそろえる**：今の見出しの最小幅（`min-width:3.5em`）だと、4文字の「広がり方」だけ値の書き出しがずれる。全部の見出しを4文字が入る幅にして、どの行も値の書き出しの位置が同じになるようにする。「（重点の問い）」の行とやり方サンプルの字下げも、その位置にそろえる（スマホ幅の字下げ1em の扱いは今のまま）
- 文字は今の `_lxEsc` でエスケープする（`markdownToHtml` は通さない。今のカードと同じ）

## §3-2 カードの中の並びと畳み（2枚とも・新形式＝`samples` があるとき）
カードを開いたときの並びを次にする：
1. お題（今のまま）
2. （重点の問い：…）（あるとき）
3. 力・広がり方・示唆（§3。あるものだけ）
4. 合図（`signal`。あるとき。今は一番下にあるのをここへ上げる）
5. **「やり方を見る」**（カードの中の `<details>`・**最初は閉じている**）。開くと中に、今のやり方サンプル（見出し「やり方サンプル（どれでも・自分流でも可）」と①②③）と「なぜ今」（`whyNow`）を今の見た目のまま出す。サンプルも「なぜ今」も無ければ、この「やり方を見る」ごと出さない
- 「やり方を見る」の行は件数を出さない（「3つ」などは書かない）。押しやすい高さ（44px 前後）にする
- 9/21 以前の旧形式（`samples` が無い）は、今のまま（お題・場面・今夜準備）に §3 の3行を足すだけで、畳まない

## §3-3 明日の予告のカードは18時まで畳む
- 「✦ 明日の予告」のカード（外側の `<details>`）は、**端末の時刻が 0:00〜17:59 のあいだは閉じた状態**（見出しの1行だけ）で出し、**18:00 以降は開いた状態**で出す。描くたびにその時刻で決める（押して開いたあと描き直されたら、また時刻で決まってよい）
- 「✦ 今日の実験」のカードはいつも開いた状態で出す
- 省略の日（`skipped`）の1行の帯は今のまま

## §4 触らないもの
- 本文の組み立て（`toMarkdown`・`markdownToHtml`）・図（visuals）・図つきのページの入口
- 週次・月次タブ（カードは出さない。今と同じ）
- ランチャー（使わない OS）

## §5 確かめること（Code 自身の確認）
1. 11/10 の daily-brief.json で、TOP に「✦ 今日の実験」「✦ 明日の予告」の2枚がこの順に出て、どちらも開くと「お題 →（重点の問い）→ 力・広がり方・示唆 → 合図 → やり方を見る（閉じている）」の順。「やり方を見る」を押すと、やり方サンプル①②③と「なぜ今」が今の見た目で出る
2. 3つの欄を消した試し（11/9 までの形）で、3行が出ず、ほかの並びは1のとおり（合図が上がり、やり方サンプルと「なぜ今」が畳まれる）
2-2. 端末の時刻を 10:00 と 19:00 にした試しで、明日の予告のカードが 10:00 は閉じ（見出しの1行だけ）、19:00 は開いて出る。今日の実験のカードはどちらも開いている
3. 3つのうち1つだけ入れた試しで、その1行だけ出る
4. `lectica_daily_practice` が無い試しで、今日の実験のカードが出ず、ほかは直す前と同じ
5. 見出しの「お題」「力」「広がり方」「示唆」「なぜ今」「合図」の値の書き出しが、PC（1280px）でそろっている
6. スマホ幅 375px で横スクロールが出ず、2枚のカードと3行が読める
試しのファイルはコミットせず、Drive にも置かない。
