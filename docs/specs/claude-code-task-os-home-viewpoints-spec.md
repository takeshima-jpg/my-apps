## 狙い
現HOMEは「今日」の1レイヤーしか映していない。VISIONと今日の間に
「いま登っている山（PJ）」と「昨日までの気づき」の視点を足し、
VISION → PJの現在地 → 今日 → 実務 という縦の階層をつくる。
追加するのは「圧」ではなく「視点」。カウント・進捗率・催促要素は入れない。

# 追加1：🧭 PJの現在地（横断ミニ）
- 配置：VISIONバーの直下。
- 内容：進行中PJごとに2行——**PJ名＋現在の問い**（1行）／**→ 次の一手**（1行）。
- 最大3件。4件以上ある場合の優先はProject OS v2.1「今どこを押すか」と同じ
  （分岐が近い→次の一手が古い→問いが長期停滞）。
- 接近中の未来分岐（14日以内）があるPJは行末に「⚡あとN日」を小さく添える。
- クリックでProject OSの該当PJ詳細へ（ランチャー内iframe運用なら遷移方法は既存の
  OS間リンクの流儀に合わせる。無ければ通常のページ遷移でよい）。
- データ源：localStorage `pos_v4`（同一オリジンのため直接読める想定。moves/核の
  実フィールド名は実コードを確認して合わせる）。
- PJが0件・核が空の場合はセクションごと非表示（空枠を出さない）。

# 追加2：💡 最近の気づき（1件）
- 配置：「今日やること」の下（今週の上）。
- 内容：直近の気づき・学びを**1件だけ**、1〜2行＋日付。クリックで出典のOSへ。
- データ源の優先順（実コードを確認して読めるものを使う）：
  1. Reflect OS（localStorage `reflectOS_v1`）：実験の learning／振り返りの気づき の最新
  2. Project OS（`pos_v4`）：kind=学び のムーブの最新
  両方あれば新しい方を1件。どちらも無ければセクション非表示。
- 「気づきを書きましょう」等の空状態メッセージは出さない（催促禁止）。
