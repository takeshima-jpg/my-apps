## §2 図つきのページへの入口（`brief-viewer/index.html`）
- 読み込んだ JSON に `report_url`（文字列）があり、`https://` で始まるとき、鮮度の帯（`.bv-fresh`）のすぐ下に1行のリンクを出す：「📊 図つきのページを開く ›」（新しいタブ・`rel="noopener"`）
- `report_url` が無いときは、本文 `brief` の中で最初に出てくる `https://claude.ai/artifact/…` の URL を代わりに使う（11/8 の週次は本文にだけ URL がある）。どちらも無ければ何も出さない（「0件」や空の枠は出さない）
- タブは問わない（毎朝・週次・月次のどれでも、あれば出す）
- 見た目：本文と同じ幅（760px）・左寄せ・高さ 44px 以上（押しやすさ）・アクセント色の文字。枠やバッジは付けない
- 本文の中の URL は今の作り（545 行付近の置き換え）ですでに押せるリンクになっている。変えない

## §3 PC 幅の整え
- 画面幅が 1024px 以上のとき、ヘッダー（ロゴ・状態・更新ボタン）とタブの並び（`.bv-tabs`）の**中身**を、本文と同じ 760px の幅で中央にそろえる（背景と下線は今のまま画面いっぱい）
- 600px 以下（スマホ）の見え方は変えない
- 本文・鮮度の帯・✦ 明日の予告・図の幅は今のまま（760px）
