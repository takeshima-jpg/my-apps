## §1 経緯（11/12・13 に決まったこと）

- ヒトメモの使い道は「つながり n／50人」（2027年12月）と「月10人以上と新しく会う」を数えること
- TOP10 と「この3か月の一手」の正本はソーシャルユニバース（SU）。ヒトメモは SU を読んで出す（`e65e94a` で ★TOP10 と詳細画面の一手は入った）
- 3つの数字を言い分ける：TOP10＝この3か月、自分から時間を使うと決めた10人／経営パートナー n／10＝関係の深さがいちばん上の人の数／つながり n／50＝つながり以上（家族を除く）の人の数

  - 赤い枠「⚠ 信頼を深める段階で30日以上接点なし」と、帯「うち30日以上接触なし n人（フラグ見直し）・信頼を深める段階で30日停滞 n人」。接点は 9/29 から記録が止まっていたので全員が該当し、催促になっている（赤は締切だけ・催促は出さない、の決まりにも合わない）
  - 緑の枠「▶ 次の経験を渡す」は `nextExperience`（前に SU から写した古い文）を出している
  - 左の欄は入力の道具（新しい人物を記録・メモからインポート・プロンプト①②③・AI更新読込）が中心
  - 右の欄に前の言葉（「階層」）と「30日停滞をアラート」の説明が残る
- 本人決定（11/13）：30日の知らせは両方外す。下の §2〜§4 を全部入れる

## §2 外す・静かにする（`hitomemo/index.html`）
1. 赤い枠（`alert-card`・2010 付近）を出さない。`staleDeepening`・`staleActive` の計算も、ほかで使っていなければ外す
2. 帯（`funnel-note`・1964 付近）は「🤝 稼働中 n人」だけにする（「うち30日以上接触なし」「フラグ見直し」「30日停滞」を外す）
3. 「◯日前」の出し方：一覧のカード・行で最後に会った日を出している所（「接触◯日前」など）は、「最後に会った日 M/D」（年が今年でなければ YYYY/M/D）と日付で出す。`lastContactDate` が無い人は何も出さない（`updatedAt` で代わりにしない・「未記録」とも書かない）。赤・オレンジの字にしない
4. 並べ替え（最終接触の新しい順／古い順）は残す

## §3 入れ替える
### 3-1 緑の枠 →「★ TOP10・この3か月の一手」
- `next-exp-card`（2024 付近）を、SU の TOP10 の一覧に替える。見出し「★ TOP10・この3か月の一手」
- 中身：`su-v6-persons` の `isTop10` の人を、`e65e94a` で入れた SU の読み方（hitoId・名前）でヒトメモの人に当て、名前（ヒトメモの登録名）と一手（SU の `nextAction`）を1行ずつ。一手は切らずに折り返す（今の「20文字で切る」をやめる）。一手が空の人は名前だけ
- 行を押すとその人の詳細へ（今と同じ）。ヒトメモに当たらない TOP10 の人は、SU の名前だけを押せない行で出す
- TOP10 が0人・SU が読めないときは、枠ごと出さない
- 色は今の緑の枠のまま（赤・オレンジにしない）。件数は出さない
- `nextExperience` はホームに出さなくなる（データは消さない。詳細画面の「次に渡す経験」の欄は今のまま）

### 3-2 一番上の数字
- 今の「経営パートナー n／10人」の大きな枠（`partner-goal`・1942 付近）を、3つの数字を横に並べた枠にする：
  - つながり n／50人（家族でなく、関係ステージが つながり・信頼を深める段階・経営パートナー の人の数。小さく「2027年12月までに50人」）
  - 経営パートナー n／10人（今の数え方のまま。小さく「2030年までに10人」）
  - 今月新しく会った人 n人（家族でなく、`createdAt` が今月の人の数。目標の数字や棒は付けない）
- 進み具合の棒は、つながりと経営パートナーの2つに付ける。色・雰囲気は今の枠に合わせる
- その下の階段（つながり → 信頼を深める段階 → 経営パートナーの人数・`funnel`）は今のまま残す
- 「家族」で絞り込んでいるときは、今と同じくこの枠を出さない

## §4 畳む・足す
### 4-1 左の欄
- 入力の道具をまとめて、`<details>`「手で直す（予備）」（最初は閉じている）の中へ入れる：＋ 新しい人物を記録／📋 メモからインポート／プロンプト①②③／🤖 AI更新読込
- 左の欄に出しておくのは：一覧・Google ドライブの状態（ログイン）・⬇ JSON保存・詳細（復旧用）
- 機能そのものは変えない（押せば今までどおり動く）

### 4-2 「記録のみ」の束
- ステージ別の束のうち「記録のみ」は最初は閉じておく（今の開閉の覚え＝localStorage に本人の操作が残っていれば、それを優先する。覚えが無いときの既定を「閉じる」にする）
- 開いたときはカードではなく1行の一覧：名前・出会った日（`createdAt` を M/D、今年でなければ YYYY/M/D）。行を押すと詳細へ
- その束の中を2つに分ける：上に「まだ決めていない人」（`tier` が「未登録」の人）、下にそのほかの「記録のみ」の人。「まだ決めていない人」が0人なら見出しごと出さない。人数のバッジ・催促の言葉は付けない（束の見出しの人数表示は今のまま）

### 4-3 絞り込み
- 絞り込み（1982 付近）に「★ TOP10」を足す：すべて／★ TOP10／パートナー形成／家族。★ TOP10 は SU の TOP10 に当たる人だけ（家族も含む）

### 4-4 右の欄（判断基準・凡例）
- 「階層　価値観の一致＋器の大きさ」の行を外す
- 「棚卸し　信頼を深める段階で30日停滞／🤝稼働中で30日接触なしをアラート」の行を外す
- 「★Top10（別軸）」を書き直す：「★ TOP10（別軸）：この3か月、自分から時間を使うと決めた10人。関係の深さとは別。ソーシャルユニバースで決める（ヒトメモは読むだけ）」
- 足す（凡例の下に「数字の読み方」として）：
  - 「つながり n／50：つながり以上（家族を除く）の人の数」
  - 「経営パートナー n／10：関係の深さがいちばん上の人の数」
  - 「TOP10：注ぎ先の10人（深さとは別）」
- 足す（「更新のしかた」として1行）：「接点は『つながり』以上の人だけ。週1回、日曜の週次で確かめた分が受信箱から入る」
- 「経営パートナー（2030目標＝10人）」などほかの行は今のまま

## §5 触らないもの
- 人のデータ（`nextExperience`・`isTop10`・`tier` ほか）は消さない・書き換えない
- 詳細画面・受信箱（`?inbox=1`）・「SUへ移行」・誕生日・面談の記録
- ソーシャルユニバース側

設計の根拠（UI心理学）：フォン・レストルフ効果（目立たせるのは TOP10 の一手だけにする）／ヒックの法則・ミラーの法則（左の欄と「記録のみ」を畳んで選ぶものを減らす）／ゲシュタルトの法則（3つの数字を1つの枠に並べて言い分ける）／損失回避（データは消さず、道具は畳むだけ）
