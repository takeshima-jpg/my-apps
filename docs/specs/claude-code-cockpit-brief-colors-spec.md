# Claude Code 実装依頼書：ランチャーOS「今日」タブのBrief見出しをカテゴリ色分け

## 目的
今日タブのBrief（要点）表示を、brief-viewer と同じカテゴリ色分けにする。
見出し語で色が変わることで、どの領域の話かが一目で分かる。

## 変更対象
launcher/index.html のみ（今日タブのbrief描画部）。

## 実装内容
brief-viewer の見出し→カテゴリ判定と配色をそのまま移植する。

### 見出し語 → カテゴリ判定（brief-viewer の _bc と同一）
```
要点 / 予定   → key
内省          → ins
財務 / 外部    → fin
事業 / 実行    → biz
人材 / 関係    → ppl
参謀 / 運用    → ops
（いずれにも該当しなければ色なし）
```
markdown→HTML変換時、`# 見出し`・`## 見出し` に上記判定でクラス（例 bcat-key）を付与する。
コックピットは1dayから移植した markdownToHtml を使っているはずなので、
その h1/h2 生成箇所に brief-viewer と同じ _bc 判定＋クラス付与を追加する。

### 配色（brief-viewer と完全一致・CSSに追加）
```
.bcat-key { color: #4f46e5; }   /* 要点・予定：インディゴ */
.bcat-ins { color: #7c3aed; }   /* 内省：パープル */
.bcat-fin { color: #0e7490; }   /* 財務・外部：シアン */
.bcat-biz { color: #ea580c; }   /* 事業・実行：オレンジ */
.bcat-ppl { color: #15803d; }   /* 人材・関係：グリーン */
.bcat-ops { color: #64748b; }   /* 参謀・運用：スレート */
```
- h1 は色に加えて下ボーダーを同色に、h2 は行頭の・/マーカーを同色にすると brief-viewer と揃う
  （brief-viewer の border-bottom-color / ::before background と同じ扱い。今日タブの既存見出しスタイルに合わせて調整可）。
- 前回の「文字サイズ拡大」と両立させる（色付けで可読性を損なわない）。

## 検証
- node --check（pre-commit）
- 今日タブのBriefで、各見出しが brief-viewer と同じ色になること
  （「今日の要点」=インディゴ、「① 内省・学び」=パープル、「② 財務・外部環境」=シアン、
   「③ 事業・実行」=オレンジ、「④ 人材・関係」=グリーン、「参謀から・運用」=スレート）
- 🔭視点補正・🔍構造・⚖️リビジット・🎁今日の一枠など判定外の見出しは色なしで正常表示されること
