## 背景
Reflect OS「⬇取り込む」画面の「プロンプト」セクションに4つのコピーボタン
（🎈Reflect壁打ち / ✨Lectica壁打ち / 💬Lectica振り返り / 📄Lecticaまとめ）があるが、
壁打ちは全てclaude.aiのプロジェクト機能で運用しているため、これらのボタンは不要。

## 変更
- 取り込み画面の「プロンプト」セクション（4つのコピーボタンとその見出し）を撤去する。
- 「貼り付けて登録」セクション（ルール表示＋貼付テキストエリア＋登録ボタン）は残す。
- 撤去はDOM非表示（display:none）でなく、該当セクションの描画を止める形が望ましいが、
  コピーボタンの生成元定数（RF_PROMPT_SPARRING 等）は他で使う可能性を考慮し**残置**してよい
  （ボタンUIだけ消す）。判断は実コードに合わせ、報告に明記。
- 「取り込む」画面の説明文が壁打ちボタン前提の文言なら、貼り付け登録に絞った文言に調整。

## 検証
- 構文検証（node --check / esbuild）
- 取り込み画面にコピーボタンが表示されない／貼り付け登録は従来どおり動作
- REFLECT-IMPORT・【振り返り】ブロックの貼り付け→登録が壊れていない
- モバイル375pxで崩れない・コンソールエラーなし
