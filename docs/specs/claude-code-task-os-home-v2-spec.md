## 思想（Project OS v2.1で確立した原則をHOMEに適用）
- HOMEの核＝「今日の一手」と「今日やること」。開いた瞬間にこれが読めること。
- 統計の常時表示・未設定カウント等の催促表示は置かない（更新の目的化を誘うため）。
- 注意情報は「該当がある時だけ」出る。ゼロの日は何も出さない。

# 変更1：統計カード3枚の撤去
- 「期限超過／今日期限／SHOT未設定」の3カードを撤去する。
- 代替：**期限超過が1件以上ある時だけ**、細い1行バナーで「期限超過 N件 →」を表示
  （クリックで該当一覧へ）。今日期限は変更3の「今日やること」内で自然に見えるため独立表示しない。
- 「SHOT未設定」カウントは完全廃止（催促の一種。未設定の把握はショット画面側の役割）。

# 変更2：今日の一手カードの刷新（Project OS v2.1整合）
- データ源を確認し、Project OS v2.1のムーブ「次の一手」（核3行と同期しているもの）を表示する。
- **スプレッドシートリンクの表示を撤去**（シートは主戦場から外れた）。
- 期日表示は原則出さない。例外として、該当PJに**接近中の未来分岐（14日以内）**があれば
  「⚡{分岐名} あとN日」を1行添える（催促ではなく事実）。
- ボタンは「Projectで開く」のみ（該当PJの詳細へ）。
- 複数PJに次の一手がある場合の選定は、Project OS v2.1「今どこを押すか」と同じ優先度
  （分岐が近い→次の一手が古い→問いが長期停滞）で1件。

# 変更3：「今日やること」を開いた状態に（主従の逆転を直す）
- 現在折りたたみの「SHOT—実務タスク」相当を、**今日分だけ既定で展開表示**する：
  今日期限のタスク＋実行中のSHOT。1行1件・チェック操作可。
- 「今週」は折りたたみのまま維持（件数バッジ付き。今日の下に配置)。
- 表示順：VISION → 今日の一手 → （期限超過バナー・ある時のみ）→ 今日やること（展開）→ 今週（折りたたみ）。

# 変更4：日付表示のバグ修正
- サイドバー下部の日付が「2026-07-17(土)」と表示される事象を確認（7/17は金曜。
  日付が前日のまま残るか、曜日計算の不整合の疑い）。
- 日付・曜日は表示のたびに現在日時から計算する形に修正。キャッシュ・初期化時固定をやめる。

# 変更5：Shot追加の操作数確認（軽微）
- ヘッダー「＋Shot」の追加フローを確認し、モーダルで複数項目を要求している場合は
  「本文＋Enterで登録（詳細は後から編集）」のクイック追加に変更する。
  既に1〜2操作で登録できるなら変更不要（報告にどちらだったか明記）。
