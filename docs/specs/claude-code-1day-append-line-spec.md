## §2 言葉の決め（この依頼書の中で）
- **保存済みの日**＝その日付に、`archived` でないログがある日。見る先は、1day の画面の中（描く・押す）では `state.logs`、受信箱の取り込み（`inboxApply`。Task OS の見えない iframe でも動く）では localStorage の `oneday_logs_v1`。どちらも「`archived` でない・`date` が同じ」で見る（今の `aixApproveByIdx` の `state.logs.find(l => l.date === targetDate)` は `archived` を見ていないので、足す下書きの分岐ではそろえる）
- **足す下書き**＝`append: true` を持つ下書き。受信箱の下書きが**保存済みの日**に届いたときに、1day の `inboxApply` が付ける。保存済みでない日に届いた受信箱の下書きには付けない（今までどおりの下書き）

## §3 Task OS（`task-os/index.html`）
1. `applyAixTasks` の下書きの取り込み（1023〜1041 付近）で、**今ある下書きのうち `append: true` を持つものは、その日付が保存済みでも捨てない**
   - 今：`for (const d of existingDrafts) { const k = keyOf(d); if (k && !loggedDates.has(k)) draftMap[k] = d; }`
   - 直し：保存済みの日付でも `d.append === true` なら残す（`inboxId` があるだけでは残さない。保存済みでない日に届いた受信箱の下書きは、その日が後で保存されたら今までどおり消える）
2. `daily-tasks.json` から来た下書き（`parsed.aix_drafts`）の扱いは変えない：保存済みの日付は飛ばす／同じ日付の今ある下書きは上書き
   - 保存済みでない日付に、受信箱の下書き（`append` なし）と `daily-tasks.json` の下書きが両方あるときは、今までどおり `daily-tasks.json` のもので上書きする（受信箱の下書きの `links`・`inboxId` は無くなる。毎朝作り直す下書きに全部入っているので、それでよい）
3. `parsed.aix_drafts` が空の配列・無いときは、今までどおり何もしない

## §4 1day（`1day/index.html`）
### 4-1 受信箱の下書き（`inboxApply`・2264 付近）
- `targetDate` が**保存済みの日**のとき：
  - 新しい下書きに `append: true` を付ける
  - `events` を行に分け（空の行は除く）、**その日のログの「できごと」にすでにある行**と**今ある足す下書きにすでにある行**は除く（行ごとに、前後の空白を取ってぴったり同じなら同じとみなす）
  - 同じ日の足す下書き（`append: true`）がすでにあれば、置き換えずに重ねる：`events`＝前の `events` ＋ 改行 ＋ 残った行。`links`＝前のものに新しいものを重ねる（同じキーは新しいもの）。`inboxId`＝新しい item の id、`generatedAt`＝今
  - 残った行が0行のとき：下書きは作らず（前の足す下書きがあればそのまま）、`{ ok:true, summary:'M/D はもう入っています（足す行なし）' }` を返す
  - `unease`・`flags` は足す下書きには持たせない（block に入っていても捨てる。足すのは「できごと」だけ）
  - summary：「M/D に足す1行を追加（承認待ち）」
- `targetDate` が保存済みでない日のとき：今までどおり（同じ日付の下書きを置き換える・`append` は付けない・summary も今のまま）

### 4-2 承認フォームの出し方（`renderAixDraftList`・2031 付近）
- **足す下書き（`append: true`）で、その日が保存済みの日**のものは、小さい形で出す：
  - 見出し：日付の右に小さく **「保存済みの日に足す」**（文字は `var(--text3)`。赤・オレンジにしない）
  - 出すのは「足す内容」の入力欄（今の「できごと」と同じ textarea。ラベルは「足す内容」。高さは最小 70px）だけ
  - **出さない**：満足度（今週は？）・ゆみさんの負荷・違和感・フラグ
  - ボタン：**「足す」**（今の「保存」と同じ見た目）と「スキップ」。**この2つのボタンは、並びの番号ではなく日付（`targetDate`）で下書きを引く**（画面を開いたまま受信箱の下書きが増えても、別の日のログに書かないように）
- 「足す」を押したとき：
  - 入力欄が空なら「足す内容を入力してください」と知らせて何もしない
  - その日のログ（`archived` でないもの）の「できごと」の末尾に改行して足す。`links` は今までどおり重ねる。`updatedAt` を今に
  - **満足度・ゆみさんの負荷（`yumiLoad`・`yumiLoadNote`）・違和感・フラグ・タグは読まない・書かない**（`window._aixSat_i`・`_aixFlags_i`・`_aixYumi_i` を見ない）
  - 下書きを消し、知らせは「✅ M/D の記録に足しました」
- 「スキップ」を押したとき：その足す下書きを消す。ログは変えない
- `append: true` なのにその日のログが無くなっている（本人がログを消した・アーカイブした）ときは、今までどおりの大きい形で出し、今までどおり「保存」で新しいログになる
- `append` の無い下書きは、今の形・今の動きのまま変えない。並び順・ナビのバッジ（`updateAixBadge`）も今のまま
