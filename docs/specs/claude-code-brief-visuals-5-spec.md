## §1 目的
図にする欄を 📚 に加えて 🎁・🧰（今日のフレームワーク）・②（財務・外部環境）に広げる。毎日は4枚まで、月曜だけ週の図を足して5枚まで（11/8 本人）。

## §2 直すところ（`brief-viewer/index.html` だけ）
1. **上限**：`BV_VISUAL_MAX` を 2 → **5**。console.warn の文言「more than 2」を「more than 5」に。上のコメントの「0〜2件」を「0〜5件」に
2. **新しい slot を2つ**（`bvVisualInsertAt()` に足す。今の `gift`・`learning`・`centerpin`・`week` は変えない）
   - `framework`：見出し行で「🧰」を含む最初の行（今は `# 🧰 今日のフレームワーク`）が始まり。**欄の終わり**＝次の**同じかそれより上の階層の見出し**（`#` の数がその見出し以下の行）・`---` の手前。手前に空行が続くなら空行より前（今の作りと同じ）
   - `market`：見出し行で「②」を含む最初の行（今は `# ② 財務・外部環境`）が始まり。欄の終わりは `framework` と同じ決め方
   - 「同じかそれより上の階層」にするのは、②や🧰の欄の中に `##` の小見出しが入っても、図が欄の途中に入らないようにするため（今の本文には小見出しは無い）
   - 本文中の「①…②…」のような箇条書きの文字では探さない（見出し行だけ）
3. **同じ slot に2枚以上**：配列の順に並べる（今の作りのままでそうなっていれば、確かめるだけ）
4. 変えないもの：1枚 60KB の上限、`<svg` で始まらないものを出さない、無害化（`bvSanitizeSvg`）、`<img>` の data URL で出すこと、見た目（幅100%・題・角丸）、`visuals` が無い・空のときに本文の HTML が前と同じこと、見つからない slot は本文の最後
5. `brief-viewer/service-worker.js` の版を上げる
