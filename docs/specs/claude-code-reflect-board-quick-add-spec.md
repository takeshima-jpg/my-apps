## 背景
- 探求ボードに問い・実験を**直接フリー入力する動線が無い**（ログ経由・取り込み経由のみ。
  実験は問いカードの「＋実験を追加」のみで、問い自体・問い未紐づけ実験を直接作れない）。
- AI取り込みで「問い・実験・習慣・思考法」が混在する。振り分け原則：
  **探求ボードは問いと検証実験だけ。習慣はRoutine OSの領分、思考法は実践原則の領分。**

# 変更1：フリー追加ボタン
- 探求ボードの候補タブ上部（または ボードヘッダー）に2ボタン：
  - **＋問いを追加**：問い本文（1行〜）＋テーマ選択（任意）→ status='candidate' で作成
  - **＋実験を追加**：実験内容＋紐づける問い選択（任意・未選択なら問い未設定）＋テーマ（任意）
    → status='candidate' で作成
- 入力は既存の実験追加と同じ流儀（最小項目・candidateなら本文だけで保存可）。
- 作成後は候補タブに即時反映・ナビ件数同期。

# 変更2：取り込み整形プロンプトへの混在防止ルール追記
取り込み画面のAI整形プロンプト（ai-prompt-text）の【ルール】に2行追記：
- 「・毎日/毎週続ける習慣は『次の実験』に含めない（習慣はRoutine OSで管理するため出力しない）」
- 「・思考法・原則めいた内容は『気づき・学び』に書く（実験にしない）」
※ RF_PROMPT_SPARRING（Reflect壁打ちv2）は改訂済みのため変更不要。
