# Claude Code 実装依頼書：100list に「AI取り込み」（貼り付けで項目追加）を実装

## 目的

毎朝briefの「新しい願望の提案×2」や壁打ちで出た願望を、**貼り付けだけで100リストに登録**できるようにする。 現状は手入力しかなく、AI提案の回収ループが閉じていない。

## 変更対象

100list/index.html のみ。**既存の項目編集・今週今月ページ・GDriveバックアップは無改変**。追加のみ。

## UI

- ナビに「🤖 AI取り込み」ページを追加（koso-log の ai-import タブと同じ構成を踏襲： 説明文＋フォーマット例＋textarea＋「登録」ボタン＋結果表示）  
- 登録後は追加件数をトースト表示し、追加された項目の一覧（タイトル・カテゴリ・予定月）を画面に出す

## 受付フォーマット（複数件対応・ブロック繰り返し）

```
【やりたいこと】
タイトル：（必須）
カテゴリ：（人生基盤/成長/経営・資産/体験/世界観・精神/遊び・偶発 のいずれか。無ければ「未分類」）
予定：（YYYY-MM または M月 または 未定。無ければ未定）
メモ：（任意・1行）
```

- 【やりたいこと】ごとに1件。区切りの `---` は無視してよい  
- ゆるい解析：ラベルは「タイトル/やりたいこと」「カテゴリ/分類」「予定/予定月/いつ」「メモ/理由」の別名を許容  
- 「予定」解析：`2026-08`→year=2026,month=8／`8月`→今年の8月（過去月なら翌年）／`未定`→year/month=null相当（既存アプリの「未定」項目と同じ持ち方に合わせる。既存データで month:null の扱いを確認して踏襲）

## 登録仕様（既存スキーマ厳守）

- 既存項目のフィールド構成をそのまま使う： `{id, no, isFocus:false, title, isCountGoal:false, countTheme:null, countTarget:null, countCurrent:0, countHistory:[], isRecurringYearly:false, year, month, scheduledDate:null, completed:false, completedAt:null, category, priority:'Medium', memo, createdAt, updatedAt}`  
- id：既存の採番方式を確認して踏襲（無ければ genUid 方式：時刻36進+乱数。Date.now()単独は禁止）  
- no：既存の最大no＋1から連番  
- **重複スキップ**：正規化タイトル（空白除去・NFKC・小文字化）が既存と一致する項目は追加しない。 スキップした件はその旨を結果表示に出す  
- 保存は既存の保存関数を使用（localStorage: yaritai\_items\_v4）

## 検証

- node \--check（pre-commit）  
- パーサ単体テスト：3件ブロック（カテゴリ別名・「8月」表記・未定・重複1件を含む）で、 追加2件＋重複スキップ1件になること  
- 既存項目の構造・件数が壊れないこと（追加のみ）

## コミット

## 補足（アプリ外・所有者向けメモ）

Cowork側は変更不要。briefの「新しい願望の提案」を採用したいときは、その文言を上記フォーマットに 整えて貼るだけ（壁打ちチャットに「これを100リスト取り込み形式にして」と頼んでもよい）。
