## 変更内容

### 1. 上限を定数にする
`tkSetQStatus` の直前あたりに追加：
```js
const TK_MAX_FOCUS_Q = 3;   /* 重点の問いの上限（変更なし） */
const TK_MAX_ACTIVE_E = 5;  /* 実験中（探求）の上限。決定検証(review)は数えない */
```
- `tkSetEStatus` の `>=3` → `>=TK_MAX_ACTIVE_E`
- `tkSetQStatus` の `>=3` → `>=TK_MAX_FOCUS_Q`（値は3のまま。定数化だけ）

### 2. 入れ替えモーダルの見出し（`tkSwapModal`）
- `kind==='q'` → `'重点の問いは最大'+TK_MAX_FOCUS_Q+'件です'`
- それ以外 → `'実験中は最大'+TK_MAX_ACTIVE_E+'件です'`
- 説明文（「新しい実験を実験中にするには、現在の実験中から1件を候補へ戻してください。」）は変更なし
- モーダルの候補リストが5件になるので、`max-height:70vh; overflow-y:auto` を `rows` に付けてスマホで収まるようにする

### 3. 探求ボードの見出し（L2577–2578）
- `' / 3'` → `' / '+TK_MAX_FOCUS_Q` と `' / '+TK_MAX_ACTIVE_E`
- 表示例：「重点の問い 3 / 3」「実験中 3 / 5」

### 4. コメント・プロンプト定数の追随
- L1961・L1972・L1989・L2099・L2193 などの「3件制限」コメントを「上限は TK_MAX_FOCUS_Q / TK_MAX_ACTIVE_E」に揃える（挙動に影響なし）
- `RF_PROMPT_SPARRING` 内の「探求ボードには重点3件・実験中3件の制限がある」→「重点3件・実験中5件」に直す。それ以外の文言（持ち帰る問いは最大1・実験は最大2の目安）は変えない
  ※ この定数は claude.ai「Reflect壁打ち」プロジェクトのカスタム指示の生成元。配置後に竹嶋さんが貼り直す（報告に一言添える）

### 5. 変えないこと
- 重点の問いの上限（3）
- 決定検証（review）の扱い（上限の外）
- `reflect_focus_v1` の形式（`focusQuestions` / `unlinkedExperiments`）。Task OS がこの形式を読むため
- データ（`reflectOS_v1`）の中身。移行処理は不要
- Lectica（L系）の実験マスタや `lectica_experiment_logs_v1` には触れない

### 6. Task OS 側の確認（原則コード変更なし）
- `homeFocusCard` は実験の件数で切っていないので、5本でも全行出る。**実機で崩れないことだけ確認**（重点3件×実験＋問い未設定の実験、合計5本を `reflect_focus_v1` に入れて HOME を表示）
- 崩れる場合のみ、`.rfc-wrap` の高さや行間を最小限に調整する（件数での切り詰めはしない。重点の写しが欠けるほうが害が大きい）

## 受入条件（playwright で実描画・`reflectOS_v1` にテストデータを投入）

1. 実験中3本の状態で、候補の実験を「実践中にする」→ **入れ替えモーダルなしで**4本目になる。同様に5本目も入れ替えなしで入る
2. 5本の状態で6本目を「実践中にする」→ 入れ替えモーダルが出て、見出しが **「実験中は最大5件です」**、候補リストに現在の5本が並ぶ。1件選んで「入れ替える」→ 5本のまま入れ替わる
3. 新規追加（モーダル）で「実践中にする」を選んだときも 1・2 と同じ挙動
4. 重点の問いは3件の状態で4件目を重点化 → 従来どおり入れ替えモーダル、見出しは「重点の問いは最大3件です」
5. 決定検証（review）の実験を active にしても、実験中の本数に数えられない（従来どおり）
6. 探求ボードの見出しが「重点の問い 3 / 3」「実験中 3 / 5」（5本なら「5 / 5」）
7. 既存データ（実践中3本・重点3本）が改修の前後で1バイトも変わらない（`reflectOS_v1` の JSON を比較。`updatedAt` も動かない＝起動だけでは保存が走らない）
8. `reflect_focus_v1` に5本分の実験が入る（`focusQuestions[].experiments` と `unlinkedExperiments` の合計が5）
9. Task OS HOME の重点カードに5本が全行表示され、375px幅でも崩れない
10. `RF_PROMPT_SPARRING` の該当文言が「実験中5件」になっている（`grep '実験中3件'` が 0 件）
11. 構文検証 OK（pre-commit hook）・コンソールエラー 0
