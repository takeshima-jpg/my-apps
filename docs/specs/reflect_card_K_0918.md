# Reflect OS宛 改修カード 追補K（2026-09-18）——パッチAI対応：取り込みの関連実験行の寛容化と壁打ちプロンプト定数の差し替え

発行：2026-09-18／起案：Cowork（参謀）／根拠：恒久ルール\_パッチAI\_2026-09-18・パッチAH\_2026-09-15／実装：開発チャット（Claude Code）側／検証：実装後の初回runnowでCoworkがバックアップから確認

## 背景

1. パッチAHで再演を「関連実験：L025（再演）」と表記する運用にした。壁打ちプロンプトv3ではブロック内をIDのみと明記したが、竹嶋さんがブリーフやShot memoからそのまま貼るケースが残る。取り込みパーサが「L025（再演）」を関連IDとして認識できないと、関連ログが空になる（8/24・8/27に関連欄が空になった事象と同じ結果）。  
2. パッチAIで朝のブリーフの✦枠が「お題→やり方サンプル→なぜ今→合図」に変わり、壁打ちプロンプトもv3（合図行・場面は壁打ちで決める・成長評価禁止・3問制限の禁止事項削除）に改訂した。ランチャー／Reflect OS内蔵のSPARRING定数（壁打ちプロンプト）が旧版のままだと、Cowork・claude.aiプロジェクト・アプリ内で3つの版が並ぶ。

## 仕様

### K-1 取り込み：関連実験行のID抽出を寛容化

- 対象：Lecticaタブ「📋 貼り付けて取り込む」のパーサ（---REFLECT-IMPORT--- ブロック）。  
- 「関連実験：」行の値から、正規表現 `/[LR]\d{1,3}/` で最初の一致をIDとして採用する。以下はすべて `L025` として扱う： `L025`／`L025（再演）`／`L025(再演)`／`L025 再演`／`関連実験：L025「相手の話を要約しすぎずに受け取ってみる」（再演）`  
- 一致が無い（空・「なし」・「該当なし」）場合は従来どおり relatedExperimentId を未設定にする（行ごと省略と同じ扱い）。  
- 任意：IDの後ろに「再演」の文字があれば `relatedNote: "再演"` をログに保存する（表示には使わない・バックアップに含める）。無ければフィールド自体を出さない。  
- 「実験ID：」行にも同じ抽出を適用してよい（`L027「共通の利益や…」` のような貼り付けを救済）。

### K-2 L主＋L関連（再演）の受け入れ確認

- 現行の双方向仕様（R主＋L関連／L主＋R関連）に加えて、L主＋L関連（主実験と異なるL系ID）を受け入れることを確認。自己参照（主＝関連）は従来どおり無効化。  
- 関連側のL実験は「実施」ではなく「関連n回」として積む（AH-3：再演は一巡の実施ログに数えない）。lastPracticedAt・実践回数の連動（追補J）は関連側では更新しない——現行仕様と同じであれば変更なし。  
- 主実験のログは1件のまま（追補Iの「ログは常に1件」を維持）。

### K-3 内蔵プロンプト定数の差し替え

- ランチャーおよびReflect OSが持つ壁打ちプロンプト定数（SPARRING系。f0384c2で同期したもの）を、Cowork発行の「Lectica実験 壁打ちプロンプト（v3・2026-09-18）」全文に差し替える。  
- 変更点の要約（定数を目視確認する用）：入力は「お題＝実験ID・実験名（あればサンプル・合図）」で場面は貼らない／設計書に「合図」行を追加／1問目は原則「今日のどの場面でやりますか」／フィードバックに「前回との比較・成長評価をしない」を追加／禁止事項から「設計フェーズで4問以上質問しない」を削除／取り込みブロックの関連実験はIDのみ（「（再演）」は書かない）。  
- 振り返り支援プロンプト（別チャット担当）は今回変更なし。

### K-4 影響範囲

- lecticaLogsのスキーマ変更なし（relatedNoteは任意追加のみ）。過去ログの再処理不要。  
- バックアップ（myapps-all-backup）にrelatedNoteが含まれれば、Coworkは週次の「一巡 N/56」集計で再演をそのまま除外できる（現状はrelatedExperimentIdの有無で判定しており変更不要）。  
- Task OS・Brief Viewer・チェッカーは変更なし。

## 検証項目（実装側）

1. `関連実験：L025（再演）` を含むブロックを取り込み → relatedExperimentId=L025、L025カードの「関連n回」が+1、主実験ログ1件。  
2. `関連実験：なし` → relatedExperimentId未設定・エラーなし。  
3. `実験ID：L027「共通の利益や価値観を使って接点を作ってみる」` → experimentId=L027で保存。  
4. L主（L017）＋L関連（L034）→ 保存され、L034側は関連としてのみ加算。  
5. ランチャーの壁打ちプロンプトをコピー → 冒頭が「Lectica実験 壁打ちプロンプト（v3・2026-09-18・パッチAI対応）」で、設計書に「合図」行がある。
