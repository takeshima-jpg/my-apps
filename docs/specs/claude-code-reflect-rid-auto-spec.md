# Claude Code 実装依頼書：Reflect の実験を実験中にしたとき R番号を自動で付ける

作成日：2026-11-03（メンテナンス担当。本人決定 11/3：A）
対象：`reflect-os/index.html` のみ
土台：main `c9ad84f`。作業前に `git pull`。

---

## 背景（なぜ）

- R番号（`rid`）が自動で付くのは R001〜R003（決まった題名と完全一致・`tkAutoAssignRids`）だけで、それ以外は編集画面の「実験ID」に手で書いたときだけ
- R番号が無い実験中は、Morning Brief の今日の実験（L系×R系）に組み込めず、Lectica のログの「関連実験」・実践の数え方ともつながらない（`lxTouchRidExps`・`lxPracticeStats` は rid で照合）
- 11/3 に実験中にした「『応援する』と『助ける』の境目を見分ける自分なりの合図を1つ決めてみる」（`muw60c7s9wvduc0pef5`）にも番号が無い
- 本人決定（11/3・A）：**実験中にしたとき、空いている次の番号を自動で付ける。完了しても番号は残り、使い回さない**

## 1. 付け方

- 実験の `status` が `active`（実験中）になった時点で、`rid` が無く、決定検証（`expType:'review'`）でなければ、**次の番号**を付ける
  - 次の番号＝すべての実験（どの状態でも。完了・保管・統合済み・やらない も含む）と、旧名で残っている `formerRid` の中で、`R` に続く数字の最大＋1。3桁ゼロ埋め（R004、R005…、R999 の次は R1000）
  - 一度付いた番号は消さない（完了・保管・やらない・候補に戻しても残る）。同じ番号は二度使わない
- 対象の経路すべて：画面の「実験中にする」（`tkSetEStatus`）・一括操作・実験の記録フォーム・REFLECT-UPDATE（`ステータス：実験中`・`■ 実験 新規` で実験中）・統合の引き継ぎで実験中になったもの・下書きから選んで実験中にしたもの
- 手で付けた番号（編集画面）が常に優先。手で付ける欄の重複チェックは今のまま（他の実験の番号は付けられない）
- 付けたら、REFLECT-UPDATE の summary に「R004 を付けました」、画面ではトースト「R004 を付けました」を1回

## 2. 統合のとき

- 実験の統合で新しい実験が実験中になる場合：統合元のうち **R番号を持つ実験中のもの**（無ければ R番号を持つもの）の先頭の番号を新しい実験に**引き継ぐ**。元の実験の `rid` は外して `formerRid` に残す（Lectica のログの関連実験の数え方が新しい実験に続くように）
- 統合元に R番号が無ければ、§1 の次の番号

## 3. 今ある実験中（起動時1回・冪等）

- 実験中（`active`・決定検証を除く）で `rid` の無い実験に、作成日の古い順に §1 の次の番号を付ける（`muw60c7s9wvduc0pef5` など）
- 退避 `reflect_backup_rid_20261103`・フラグ `reflect_rid_20261103_done`。付けた件数をトースト1回「実験中の n本に R番号を付けました」
- `tkAutoAssignRids`（R001〜R003 の題名一致）はこの移行より先に動かす（既存の対応を崩さない）

## 4. 変えないこと

- R001〜R003 の題名一致の割り当て、`lxTouchRidExps`・`lxPracticeStats`（rid で照合）、Lectica の実験マスタ（L系）
- 候補・保管・完了のままの実験には付けない（実験中になった時点で付ける）

## 5. 受入条件（playwright・11/3 以降のバックアップ相当）

1. 起動で、R番号の無い実験中に次の番号（今のデータなら R004 から）が付く。退避1つ・再読み込みで二度走らない
2. 候補の実験を画面で実験中に → 次の番号。REFLECT-UPDATE `ステータス：実験中`・`■ 実験 新規`（実験中）・下書きから実験中も同じ。summary／トーストに番号
3. 実験中の R004 を完了 → R004 が残る。次に実験中にした実験は R005（R004 を使い回さない）
4. 手で R010 を付けた実験がある → 次の自動は R011
5. R002（実験中）と候補を統合 → 新しい実験が R002、元は `formerRid:'R002'`。Lectica のログ（関連実験 R002）の実践数が新しい実験に出る
6. 決定検証の実験には付かない
7. 「直前の更新を元に戻す」で戻る。375px・コンソールエラー0・構文検証OK・SW版上げ

## 6. コミット

「reflect-os: 実験を実験中にしたとき R番号を自動で付ける（次の番号・使い回さない・手で付けた番号が優先）。統合は統合元の R番号を引き継ぐ。今ある R番号の無い実験中に起動時1回だけ付ける。R番号が無いと Morning Brief の今日の実験と Lectica のログにつながらないため（11/3 本人決定）」

## 7. 報告

変更箇所／起動時に付けた番号と実験の題名／受入7項目。実装を止める場合のみ質問を1つ。
