# Claude Code 実装依頼書：ランチャーOS 表示調整（タイトル・アイコン差別化・文字サイズ）

launcher/index.html および manifest/アイコン類の調整。3点。

## 1. アプリ名を「ランチャーOS」に統一
- manifest.webmanifest：`"name": "ランチャーOS"` / `"short_name": "ランチャーOS"`
- <title> を「ランチャーOS」に
- 現在「my-apps コックピット」「竹嶋OS — コックピット」等の表記が混在しているので、
  UI上の表記（ヘッダ・タイトル・ホーム追加時の名前）をすべて「ランチャーOS」に統一する。

## 2. アイコンを Task OS と明確に区別できるデザインに
問題：タスクバー/ホームでコックピットとTask OSのアイコンが似ていて見分けにくい。
- 基本方針（濃色ベース・静か・SVG自作・maskable）は維持。
- **Task OSと図柄・色で明確に差別化**する。Task OSは「チェック/タスク」系の意匠なので、
  ランチャーOSは別モチーフにする。案：
  - 中央に大きめの「◉ ハブ（中心の輪）」から各OSへ伸びる放射、または
  - グリッド状に配置された複数の点を「1つの枠」が囲む＝「集約・司令塔」の意匠
- **背景色をTask OSと変える**（Task OSの基調色を確認し、それと十分コントラストのある濃色に。
  例：ランチャーOSは濃紺#1E2A44系、差し色は控えめに1色）。
- パッと見て「これは各OSをまとめる親アプリ」と分かる、他OSアイコンと一線を画す見た目にする。
- icon.svg / favicon.svg / icon-192 / icon-512 / icon-maskable-512 / apple-touch-icon をすべて更新。
- 実装前に**2〜3案をSVGで見せて**ほしい（所有者が選ぶ）。迷えばハブ＋放射案で。

## 3. 全体の文字サイズを大きく
- 左タブバーのラベル、今日タブのbrief本文・見出し・タスク行など、**全体的に文字が小さい**。
  ベースフォントサイズを引き上げる（例：body基準を1〜2px上げ、見出し・タブラベルも比例拡大）。
- 特に読み物である「今日のBRIEF（要点）」は可読性重視でやや大きめに。
- モバイルでもタップしやすいよう、タブ・ボタンの最小タップ領域を確保。
- 憲章のトーン（静か・余白）は保ち、詰め込みではなく「読みやすい大きさ」に。

## 検証
- node --check（pre-commit）
- インストール名・タイトルが「ランチャーOS」で表示される
- タスクバー/ホームでTask OSと並べても一目で区別できる（アイコン確認）
- 文字が全体的に大きく読みやすい／レイアウトが崩れない（PC・モバイル幅）
