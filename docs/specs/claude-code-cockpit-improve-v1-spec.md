# Claude Code 実装依頼書：launcher（統合コックピット）改善v1

初回実装おつかれさま。実運用で出た改善5点。launcher/index.html のみ変更、各OSは無改変。

## 1. 左タブのアイコンを各OS実物に統一
- 現在フリー素材の絵文字/汎用アイコンになっている。各OSの実際のファビコン/ロゴに合わせる。
- 実装方針：各OSページの `<link rel="icon">` またはヘッダのロゴを確認し、同じ絵柄・色に寄せる。
  難しい場合は、各OSのブランド色（task-osのソース色 ショット#8DC63F/ルーチン#3AA655/プロジェクト#7C5CD6 等、
  各OSのテーマ色）でアイコンの色を統一するだけでも可。**各OSを開いたときの見た目と左タブが一致する**ことが目標。
- 「今日」タブは 🏠 のままでよい。

## 2. 右側の余白を解消
- 現在メインエリア右側に大きな空白がある。iframe/コンテンツをメインエリア幅いっぱいに広げる。
- 「今日」タブのbrief等のコンテンツは最大幅（例 max-width:900px）で中央寄せにして読みやすく、
  それ以外（iframe各OS）は幅100%で表示。右の死に余白を無くす。

## 3. 「今日」タブのクイック追加バーを固定（sticky）
- brief本文をスクロールすると上部の「今日のShotタスクを追加…」バーが消えてしまう。
- クイック追加バーを今日タブ上部に **position:sticky; top:0** で固定し、スクロールしても常に入力できるようにする。
- brief・タスク一覧はその下でスクロールする構成に。

## 4. Googleログイン導線を親切にする
- 現状ヘッダ1行ヘルプのみ。以下を追加：
  - 各iframeタブのミニヘッダに「🔑 ログイン」ボタンを常設（＝そのOSを別タブで開く＝ログイン用。↗と統合でよい）
  - GDrive未接続を検知できる場合（iframe内OSのlocalStorageトークン有無をシェルから確認できる範囲で）、
    未接続なら小さく「未接続」バッジを出す。判定が難しければヘルプ文言だけ「初回はどれか1つのOSでGoogleログインすれば全OSで有効」に更新。
- ※OAuthはiframe内で実行不可のため、ボタンは必ず別タブ起動。この制約はコメントに明記。

## 5. 「今日」タブに AI参謀タスクの取り込み導線を追加
- 現在、今日タブは今日のShotタスク表示のみで、CowworkのAIタスク（aix-tasks.json）を取り込む導線が無い。
- 今日タブのクイック追加バー付近に「🤖 AIタスク読込」ボタンを追加。
  押したら **Task OSを別タブで開く**（Task OS側の既存「🤖AIタスク読込」を使ってもらう導線）。
  ※ シェルから直接 applyAixTasks 相当を実行すると、Task OS側のロジック（台帳 aix_imported_keys・
  lectica_daily_practice処理等）を複製することになり二重管理になるため、**取り込み本体はTask OSに任せ、
  シェルは導線（別タブ起動）だけ**にする。読込後にシェルへ戻って今日タブを⟳すれば新タスクが反映される。
- ボタン脇に1行：「AIタスクの取り込みはTask OSで（読込後この画面を⟳）」
