# 依頼書：PROJECT-IMPORT で「核・見立て」も更新できるようにする（Project OS v2.3）

作成日：2026-10-01
依頼元：壁打ちチャット（3AHD2030構想の見直し中に発生）
対象：project-os/index.html（PROJECT-IMPORTパーサ周り）
優先度：中（壁打ち側のプロンプト差替えと同時に稼働させたい）

---

## 1. 背景・目的

壁打ちの流れでゴール／注意論点／成功条件／悪い未来／センターピンを見直したとき、現状は「⬇取り込む」に貼れず、旧モーダルで手編集するしかない。
ムーブ（決定/学び/分岐/次の一手/問い）と同じく、PROJECT-IMPORTブロックから核・見立ても更新できるようにする。

v2.2で見立て4項目（成功条件／悪い未来／センターピン／注意点）とゴールはPJのフィールドとして既に存在するため、**スキーマ変更は不要**。パーサの拡張と履歴の残し方だけが本件のスコープ。

## 2. 追加するラベルとフィールド対応

| IMPORTラベル | PJフィールド（要コード確認） | 備考 |
|---|---|---|
| `ゴール:` | goal | 既存 |
| `注意論点:` | attentionIssue（旧「注意点」） | ラベル名はこれに統一（下記3-3） |
| `成功条件:` | successConditions | v2.2で昇格済み |
| `悪い未来:` | badFuture | v2.2新規 |
| `センターピン:` | centerPin | v2.2新規 |

※フィールド名は v2.2 実装時の命名に合わせること。上表は壁打ち側の認識なので、実コードが優先。

## 3. 仕様

### 3-1. パーサ
- 既存の `---PROJECT-IMPORT---` 〜 `---END---` ブロック内で、上記5ラベルを認識する。
- 1ラベル1行。値はラベル以降の文字列全体（改行なし）。
- 5ラベルは**上書き（置換）**。追記ではない。
- ラベルが無ければ何もしない（既存値を保持）。空値（`ゴール:` のみ）は**無視**し、クリアには使わない（誤消去防止）。
- 既存ラベル（PJ/決定/学び/分岐/次の一手/問い）の処理は変更しない。
- `問い:` と同じく、1ブロック内に同じラベルが複数あれば最後を採用。

### 3-2. 履歴（設計憲章「アーカイブ・削除しない」に準拠）
- 上書き時、旧値と新値を1件のムーブとして自動追記する。
  - 種類：既存の種類に増やさず「学び」で代用するか、新種類「見立て更新」を追加するかは実装側判断。**種類を増やす場合は壁打ちコンテキスト出力・ホームカード・Task OS HOME読取（pos_v4）に影響しないことを確認**。
  - 本文の形：`センターピン更新：「旧…」→「新…」`
  - 旧値が空の場合は `センターピン設定：「新…」`
- 旧値と新値が同一なら、ムーブは作らず何もしない。

### 3-3. ラベル名の統一
- OS側の表示ラベル「注意点」を「注意論点」に改名する（壁打ちコンテキスト出力・インライン編集ラベル・共有用エクスポートの3か所）。
- データキー（attentionIssue等）は変えない。

### 3-4. 壁打ちコンテキスト出力
- 単体版400字以内の制約は維持。本件で出力内容は変えない（見立て4項目はv2.2で含有済み）。

## 4. 受入条件
1. 5ラベルを含むIMPORTブロックを⬇取り込むに貼ると、該当フィールドが置換され、詳細画面に即反映される。
2. 置換ごとに旧→新のムーブが1件追加され、ムーブ一覧で読める。
3. 5ラベルを含まないIMPORTブロックの挙動は従来と完全に同一（既存のテストケースで回帰なし）。
4. 空値ラベルはフィールドをクリアしない。
5. 「注意点」表記が「注意論点」に統一されている（3か所）。
6. 単体版コンテキスト出力が400字以内のまま。
7. myapps-all-backup のcollect/restoreで新ムーブが欠落しない。

## 5. やらないこと
- 新画面・新モーダル・催促要素は作らない。
- 分岐予定／これまでの動きの一括置換はスコープ外。
- Cowork（Morning Brief）側の変更は不要（読取側のため）。

## 6. 連動作業（Claude Code外）
- 壁打ちプロンプトを v2.2 に差替え（同梱 `project-sparring-instructions-v2-2.md`）。claude.aiの「Project壁打ち」プロジェクトのカスタム指示を置換する。
- 恒久ルールへの追記は不要（Cowork非関与）。

## 7. テスト用サンプル

```
---PROJECT-IMPORT---
PJ: 3AHD2030構想
センターピン: 幹部共同編集で、構想を各管掌の90日アクションに翻訳する。
悪い未来: 竹嶋の頭の中の構想で終わる。合宿で意見を出し切らず文書に落ちない／全体の責任が言葉にならない幹部が一人でもいる。
問い: 計画が達成できない事象が起こるとしたら何か？その事象に対して策は打てているか？
---END---
```
期待：センターピンは同一なので無変更・ムーブなし／悪い未来は置換＋ムーブ1件／問いは従来どおり。
