## 1. 持ち越した Shot が残っている日も、参謀の新しい実験の Shot を足す（Task OS）

**いま**：`autoGenLecticaShot` は、当日に未完了（todo/doing）の Lectica Shot があると「open別実験を尊重」で新しい提案を足さない（2066行付近）。「後でやる」で翌営業日に送った Shot がこれに当たり、その日は参謀の新しい実験が Shot にならない。

**直し方**：
- `openShot` の判定から、**持ち越した Shot** を除く。持ち越した Shot＝`lecticaDetail.result==='later'`、または memo の先頭行が `持ち越し：` で始まるもの
- 持ち越し以外の open な Lectica（参謀の提案由来・手動追加）は今までどおり尊重して何もしない（【厳守】のまま）
- 持ち越した Shot は**書き換えない・消さない**。新しい提案は別の Shot として足す（同じ実験IDが当日に既にあれば足さない＝今の冪等の判定はそのまま）
- コンソールの `[lectica-sync]` に分岐名 `create`・理由「持ち越しあり→提案を新規追加」を残す

**受入**：
1. 前日に「後でやる」で今日へ送った Shot（実験A）がある状態で、今日の提案（実験B）を同期 → A はそのまま、B が新しく1件。HOME に A と B の2件が並ぶ
2. 提案が A と同じ実験ID → 足さない
3. 持ち越しでない open な Lectica（参謀の提案由来）がある日 → 今までどおり足さない
4. 再同期で B が二重にならない

## 2. Shot Task OS の実験カードに結果の印（Shot Task OS）

**いま**：Lectica のカードは memo の代わりに実験の詳細を表示するので、`結果：` 行が見えず、やった／やってない の区別が画面で分からない。

**直し方**：
- `lecticaDetail.result` がある Lectica のカードに、題名の近くへ小さな印を1つ出す：`結果：やった`／`結果：やってない`／`持ち越し`（`later` のとき）
- 色は控えめ（灰色系の文字か薄い枠）。**赤は使わない**（赤は締切専用）。「やってない」も責める色にしない
- `result` が無い古い Shot は何も出さない（memo の「結果：」行だけある場合も出さなくてよい）
- Task OS の HOME の行には足さない（行を増やさないため）

**受入**：
5. result が done／not_done／later のカードにそれぞれの印、無いカードには無し。375px で折り返しても崩れない

## 3. 全タスク一覧の一括削除（Shot Task OS `bulkDelete`）

**いま**：選択した Shot を `confirm` 1回でまとめて消す。実験の Shot も3択を通らずに消える（結果が残らない）。

**直し方**：
- 選択に、**結果の無い**実験の Shot（`category:'Lectica'` で `lecticaDetail.result` が無いもの）が含まれていたら、それは一括削除から**外す**。外した件数をトーストで1回：「実験のShot n件は外しました（1件ずつ結果を選んで消せます）」
- 結果が付いている実験の Shot と、Lectica 以外の Shot は、今までどおり消える
- 確認文は消す件数（外した後の件数）で出す。全部外れて0件なら確認を出さずにトーストだけ

**受入**：
6. Lectica（結果なし）2件＋通常3件を選んで一括削除 → 確認は「3件」、通常3件だけ消え、トーストが1回
7. Lectica（結果あり）は一括削除で消える
