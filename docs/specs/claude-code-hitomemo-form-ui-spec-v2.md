# Claude Code 実装依頼書 v2：ヒトメモ編集フォームのUI改善（＋「家族」を関わり方タイプに追加）

## 目的
関係ステージ改修後の編集画面が入力しにくい。特に「次に渡す経験」が小さすぎる。
選択式はボタン化して押しやすく。あわせて関わり方タイプに「家族」を選択肢として追加する。

## 変更対象
hitomemo/index.html（詳細/編集画面のフォーム）。データ値・保存ロジックは無改変（入力方式と選択肢追加のみ）。

## 1. 「次に渡す経験」フォームの拡大【最優先】
- 小さな textarea を複数行が見える大きさに（min-height 4〜5行分・幅は入力欄いっぱい・resize:vertical維持）。
- 他の長文欄（経歴・背景／個性・傾向／印象・洞察／価値観／メモ）も、内容が複数行あるものは高さを確保。

## 2. 選択式項目をpillボタン選択に
- **関係ステージ**：記録のみ / つながり / 信頼を深める段階 / 経営パートナー を横並びpillボタン（単一選択）。
  選択中はステージ色（記録のみ=グレー/つながり=青/信頼を深める段階=amber/経営パートナー=緑）。
- **関わり方タイプ**：**育成（若手）/ 共同成長（同世代）/ 相互学習（年上・専門家）/ 維持（確定パートナー・専門家）/ 家族**
  の5択pillボタン（単一選択）。※「家族」を新規追加。
- pillボタンはタップ領域を十分に（高さ36px以上・余白確保・モバイル折り返しOK）。
- **（参考）仕事役割 roleStage**：ドロップダウンのまま小さく畳んで表示。

## 3. 「家族」追加の扱い【重要・データ保護】
- 関わり方タイプ（engagementType）の選択肢に「家族」を正式追加する。保存値もそのまま「家族」。
- **旧データ保護**：roleStage や engagementType に、選択肢に無い旧値（「家族」等）が入っている人物は、
  その値を消さず保持・表示する。選択肢に一致しない旧値が来ても「未設定」に上書きしない
  （pillボタンは一致するものをハイライト、一致しなければ現在値をそのまま保持表示）。
- AI更新読込パーサ：engagementType の受付に「家族」を追加（既存の育成/共同成長/相互学習/維持の判定に1つ足す）。

## 4. フォーム全体の整理
- ラベルと入力欄の間隔・グループ余白を整える（憲章の余白・静かなUI）。
- 「🤝 稼働中」チェックボックスはラベル全体クリックで切替（タップ領域拡大）。
- 「最終接触日」に「今日」ボタンを添える（任意・あれば便利）。凡例パネル（右）は現状維持。

## やらないこと
- stage / isActive / roleStage / engagementType のデータ値・保存処理の仕組みは変更しない
  （選択肢に「家族」を足すのと、入力UIのボタン化のみ）。
- AI更新読込・自動取込・重複検出のロジックは無改変（engagementTypeの受付値追加を除く）。

## 検証
- esbuild --jsx=transform で構文検証
- 関係ステージ・関わり方タイプをボタンで選ぶと従来と同じ値が保存される。「家族」選択→保存→再表示で保持
- roleStage/engagementType に旧値「家族」が入った人物で、値が消えず表示される（未設定に飛ばない）
- 「次に渡す経験」ほか長文欄が複数行見える。モバイル幅でボタンが折り返しても崩れない
- AI更新読込で engagementType「家族」が反映される
