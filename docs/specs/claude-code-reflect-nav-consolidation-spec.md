# Claude Code 実装依頼書：Reflect OS 導線整理（①〜③）＋重点スナップショットのlocalStorageミラー

作成日：2026-08-18
対象：`reflect-os/index.html`
作業前に `git pull`。

## 背景
導線が多く、同じものに行く道が複数ある・フィルタがナビに昇格している・「過去を見る」入口が2つある。
①〜③で整理し、あわせてTask OS表示（別依頼書B）用に重点データをlocalStorageへミラーする。

## ① ホーム「現在の重点」を閲覧専用にする

現状、ホームの「現在の重点」は `tkQCard(q,true)` で探求ボードの重点タブと同じ編集操作つきカードを描いている。
同じ操作が2画面でできると、どちらでやったかの記憶が割れる。

- ホーム側のカードから**編集・状態変更の操作ボタン類を出さない**（閲覧専用の描画にする）。
  `tkQCard`に閲覧専用フラグを足すか、ホーム専用の軽量カードにするかは実装に任せる
- カード自体のクリック（または既存の「→ 探求ボードを開く」）で探求ボードへ遷移できれば操作は失われない
- 「⚠ 問い未設定の実験」の警告表示はホームに**残す**（気づきの価値があるため）。ただしこちらも閲覧専用
- 探求ボード側は一切変更しない（編集はここに集約される）

## ② ナビ「テーマ未紐づけ」をログ内フィルタに降ろす

- サイドナビから `unthemed-btn` を撤去する
- ログ画面の上部に**フィルタチップ**「△ テーマ未紐づけ（n件）」を置く。クリックでトグル（現行の `S.unthemedOnly` をそのまま使う）
- 件数バッジはナビ「ログ」項目の右に移す（0件なら非表示）。現行の警告色トーンは維持

## ③ 「検索」を「アーカイブ」に統合する

- サイドナビから「検索」を撤去する
- アーカイブ画面の**最上部に検索ボックス**を置く。検索実行時は現行の検索結果描画をそのまま使う
  （検索対象・ロジックは変更しない。置き場所の統合のみ）
- タブ名は「アーカイブ」のまま。`S.tab==='search'` への内部遷移が残っている箇所があれば `archive` に付け替える
- 検索の既存レンダラは流用し、重複コードを増やさない

ナビは10→8項目になる：ホーム／ログ／探求ボード／意思決定検証／Lectica／アーカイブ／VISION設定／取り込む

## ④ 重点スナップショットをlocalStorageへミラーする【依頼書Bの前提】

Reflectのデータ本体はIndexedDBにあり、Task OSから読めない。同一オリジンのlocalStorageに軽量ミラーを書く。

- キー：`reflect_focus_v1`
- 書くタイミング：**初期化完了時**と、**`tkSave('questions',…)`／`tkSave('experiments',…)` の後**（tkSave内にフックしてよい）
- 内容（この形を厳守。依頼書BのTask OS側がこれを読む）：

```json
{
  "updatedAt": "2026-08-18T10:00:00.000Z",
  "focusQuestions": [
    { "id": "...", "title": "問いのテキスト",
      "experiments": [ { "id": "...", "title": "実験タイトル", "scene": "使う場面" } ] }
  ],
  "unlinkedExperiments": [ { "id": "...", "title": "...", "scene": "..." } ]
}
```

- `focusQuestions` = `tkFocusQs()`（status==='focus'・最大3）。各問いの `experiments` はその問いに紐づく `tkActiveEs()` のみ
- `unlinkedExperiments` = `tkActiveEs()` のうち `questionId` が null または focus外の問いに紐づくもの
- 決定検証（`tkIsReview`）は**含めない**
- 書き込みは try/catch で守り、失敗してもUIを止めない

## 検証
- 構文検証（node --check）
- ホームの重点カードに編集操作が出ない・探求ボードへの遷移は生きている・探求ボード側は従来どおり編集できる
- ナビからテーマ未紐づけ・検索が消え、ログ内チップと（バッジ）・アーカイブ内検索が機能する
- 検索結果の内容が統合前と一致する
- 問いの重点化・実験のactive化・タイトル編集のそれぞれ直後に `reflect_focus_v1` が更新される
- 重点0件・実験0件でもエラーにならない（空配列で書く）
- スマホ幅で崩れない・コンソールエラーなし
