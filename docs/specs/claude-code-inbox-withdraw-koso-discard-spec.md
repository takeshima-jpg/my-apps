## §3 構想ログ：廃棄の相手がもう無いとき（`koso-log/index.html`）
- `applyKosoBlock()` の `b.op==='discard'`：相手の id が `items` に無いときは、**エラーにせず**、`{ summary: '{id} は見当たりません（もう無いので廃棄は済み扱い）', ids: [] }` を返す。理由（`理由：`）が無くてもこの扱いにする
- 相手があるときの動き（理由が無ければエラー・廃棄済みならアーカイブを足さない）は変えない
- **統合（`■ 統合：`）・PJ化（`■ PJ化：`）・試しの新規の親（`親：`）で相手が無いときは、今までどおりエラー**（相手が無いと結果が変わるので、保留に残して本人が見る）
