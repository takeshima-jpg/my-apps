## §2 直すこと（`task-os/index.html`・`gdAutoSync`・3299〜3311 付近）
1. 週次スナップショットの書き込み（`gdUpload(GD_WEEKLY_PREFIX + …)` と `gdPruneWeekly()`）を、**同期の本体から外して、同期が終わった後に待たずに走らせる**
   - 同期の本体の順は：日次タスク → ヒトメモ → 実験の Shot → 集める → 毎朝用を書く → 受信箱を読む → 受信箱を配る合図 → 「同期できた」の表示。ここまでで同期は終わり（ボタン・トーストは今のまま）
   - その後、裏で：週次スナップショットを書く → 成功したら `taskos_weekly_uploaded_ymd` を今日にする → 古い週の掃除（`gdPruneWeekly`）
2. 書くかどうかの決め方は今のまま：自動の同期は1日1回（`taskos_weekly_uploaded_ymd` が今日なら書かない）、「同期」ボタン（manual）は毎回書く。「今日」は今までどおり同期の本体の中で取った日付（`todayYmd`）を使い、裏の書き込みが成功したらその日付を入れる
   - **裏の書き込みを始めるのは、同期の本体が最後まで通ったときだけ**（途中で失敗・401 のときは始めない）
3. 書く中身は今のまま（その同期で集めた `fullSnap` の完全版・字下げなし・ISO 週のファイル名・同じ週は上書き）
4. **裏の書き込みが走っている間に次の同期が始まったら、その同期では週次を書かない**（二重に書かない。目印は変数1つでよい）。その同期の記録は `steps.uploadWeekly: 'busy'`（「同期」ボタンの回でも書かない。その回の新しい中身は、次に書く回に入る）
5. 裏の書き込みが失敗したとき・途中でタブを閉じたとき：`taskos_weekly_uploaded_ymd` を今日にしない（次の同期でまた書く）。画面には何も出さない（`console.warn` だけ）。**401（ログイン切れ）のときは `gdClear()` だけを呼ぶ**（ボタンが「☁️ GDrive接続」に戻る。`gdSetStatus` は呼ばない＝今の同期の 401 の所は `gdSetStatus('ok')` がボタンの字を「☁️ GDrive同期」に戻してしまうので、まねしない。アラートも出さない）。裏の書き込みは必ず自前の `catch` で受ける（受けないと 401 でも `gdClear()` が動かない）
6. 時間の記録（`taskos_sync_timing_v1`）：
   - その同期の記録の `steps.uploadWeekly` は、書かない回は今までどおり `'skip'`、裏で書く回は `'bg'`
   - 裏の書き込みが終わったら、`taskos_sync_timing_v1` の中の同じ記録（`at` が同じもの）を**書き換えて**保存する（`weeklyBgMs`＝ミリ秒。失敗したら `'fail'`）。`gdTimingSave` は先頭に足すだけなので、そのまま呼ぶと記録が2件になる。`at` で探して置き換える小さい関数を足す
   - `totalMs` は同期の本体だけの時間（裏の書き込みを含めない）
7. 同期の表示（`gdSetStatus`）は、裏の書き込みの間も「同期できた」のまま変えない
8. 説明の書き足し：`docs/specs/claude-code-taskos-sync-shorter-spec.md` と `CLAUDE.md` の `uploadWeekly` の説明（今は `'skip'` だけ）に、`'bg'`・`'busy'`・`weeklyBgMs` を1行ずつ足す

## §4 確かめること（Code 自身の確認）
1. 自動の同期（その日の1回目）：`steps.uploadWeekly` が `'bg'`、`totalMs` に週次の時間が入っていない。少し後に同じ記録へ `weeklyBgMs` が入り、Drive 相当の書き込み（試しでは `gdUpload` の呼び出し）が1回、`taskos_weekly_uploaded_ymd` が今日になる
2. 同じ日の2回目の自動の同期：`'skip'`、週次の書き込みが呼ばれない
3. 「同期」ボタン：同じ日でも裏で書く
4. 裏の書き込みを失敗させる（試しで例外）：`taskos_weekly_uploaded_ymd` が今日にならず、`weeklyBgMs` が `'fail'`、画面に何も出ない。次の自動の同期でまた書く
5. 裏の書き込みが終わる前に次の同期を始める：週次の書き込みが二重に呼ばれず、その回の記録が `'busy'`。`taskos_sync_timing_v1` に同じ `at` の記録が2件できていない
6. 裏の書き込みで 401：ボタンが「☁️ GDrive接続」に戻り、アラートが出ない。同期の本体が途中で失敗した回は、裏の書き込みが始まらない
7. 毎朝用のバックアップ・受信箱の取り込み・実験の Shot が今までどおり動く。毎朝用の中身（キーの並び）が直す前と同じ
8. 書かれた週次スナップショットの中身が、直す前の作りと同じ（同じ `fullSnap` を `JSON.stringify` したもの）
