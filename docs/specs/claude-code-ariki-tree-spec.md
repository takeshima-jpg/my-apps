## §2 Reflect OS：在り方の木（`reflect-os/index.html`）

### 2-1 置き場所
- `renderTankyu()`（3259〜）の先頭、`.tk-hd`（件数の行）より**上**に、新しい区画 `.ariki`（在り方の木）を置く。見出しは小さく「在り方の木」。
- 既存の重点／候補／実践原則／完了のタブ、`tkStoredFold()` はそのまま下に残す。

### 2-2 形（PC・左から右の4列）
- 列1 **VISION**：`loadVisionShared()` の `vision`（配列）を1枚のカードに。薄い緑の枠（`--go-lt` 背景・`--go-bd` 枠）。無ければ列1は空（帯を出さない）。
- 列2 **テーマ**：`rfPickThemes()`（`detached` でなく `status!=='完了'`）。並びはホームの探求テーマの並び（`renderHome` でテーマカードを並べる直前の並べ替え＝優先度→状態）と同じ。
- 列3 **重点の問い**：各テーマの `status==='focus'` の問い（`themeIds` にそのテーマを含む）。
- 列4 **実験**：各重点の問いに `questionId` でつながる実験のうち `status==='active'`（実験中）。
- 列の間は細い線（`--bd` より少し濃い灰）で、親→子を**縦の幹＋横の枝**でつなぐ（デザインシート「在り方の木 イメージ」の図解パターンと同じ）。1つの親から複数の子へは、親の右端から縦線を下ろし、各子へ横線。
- 描き方は SVG でも CSS でもよい。**カードの高さが中身で変わる**ので、線は描画後の実寸から引く（固定座標にしない）。

### 2-3 実験の行に出すもの
- R番号（`rid`。無ければ出さない）・題名・状態バッジ（`tkStBadge` を流用）。
- 「場面」：`scene` を1行。空なら小さく「場面なし」（`--mu` 色）。
- 実践回数：`lxPracticeStats(x.rid, logs).total` を「実践 n回」（rid が無い実験は出さない）。これは**事実の数字**で、件数バッジではない（催促にしない）。
- 人の紐づけ（`links.personNames`）は今のチップのまま出してよい。**PJ・戦略目標の印は出さない**（`52085ad` で外した）。

### 2-4 完了した実験
- 完了（`complete`）・原則化（`principled`）の実験は、`questionId` で問いにつながっていない（テーマにだけつながる）ものが多い。問いの下には出さず、**テーマのカードの下に「▸ 完了した実験を見る」**（折りたたみ・既定は閉じる）を置き、そのテーマの `themeIds` を持つ完了・原則化の実験を薄く（`--di` 色）一覧する。本数は出さない。
- 完了が0本のテーマにはこの折りたたみ自体を出さない。

### 2-5 目立たせるのは2つだけ（フォン・レストルフ効果）
- 重点の問いが無いテーマ → テーマ名の横に「重点なし」。
- 実験中が無い重点の問い → 問いの横に「実験中なし」。
- どちらも**黄土色**（文字 `#8a5300`・背景 `#fbf0dc`）。赤は使わない（赤は締切だけ）。ほかに色を変える要素は作らない。

### 2-6 木の下の1行
- 「候補の問い n本 ・ 候補の実験 n本」を薄く1行（`status==='candidate'` の数。`draft`・`draft_dropped`・`stored` は数えない）。0本のものは書かない。両方0なら行ごと出さない。
- **実践原則の本数は出さない**（探求ボードの「実践原則」タブで見える・11/3 本人決定）。

### 2-7 描き直しのタイミング
- 探求ボードを開くたびに描く（今の `renderTankyu` と同じ）。
- `storage` イベント（397〜）は今 `reflectOS_v1` だけで `location.reload()` する。これに **`lectica_experiment_logs_v1`（実践回数のもと）と `myapps_vision`（VISION）** を足し、どちらが変わっても描き直す（reload でも `ra()` の呼び直しでもよい。入力中の保護は今の reload と同じ扱いでよい）。

### 2-8 出さないもの・変えないもの
- 「重点の問いにつながっていない実験中」「テーマにつながらない重点の問い」の列や枠は**木に作らない**（11/3 本人決定。下の既存の一覧にはそのまま出る）。
- 件数バッジ・催促・「0件」表示は出さない（2-6 の数字は本数の事実であって、未処理の催促ではない）。
- `reflect_focus_v1`（Task OS 向けミラー `tkMirrorFocus`）の中身は変えない。
- スマホ幅の確認は不要（11/3 本人：Reflect OS はスマホで開かない）。ただし横スクロールが出ても壊れない程度でよい。
