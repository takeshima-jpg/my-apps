# Claude Code 実装依頼書：launcher を「統合コックピット（シェル）」に昇格

## 目的
11個のOSを毎回別ページで開くクリック工数を消す。左タブバー＋iframeのシェルを作り、
体感を「1つのアプリ」にする。**各OSのコードは一切変更しない**（ゼロリファクタが絶対条件）。

## 変更対象
launcher/index.html を全面改修（シェル化）。他OSは無改変。
※ 既存どおり各OSのURL直アクセスも今まで通り使える（何も壊さない）。

---

## 1. シェルの構成

- **左サイドバー（固定・幅細め）**：タブ一覧。上から
  `🏠 今日 / ✅ Task / ⚡ Shot / 🔁 Routine / 📊 Project / 📓 1day / 💭 Reflect / 💡 構想 / 💯 100 / 🌌 SU / 👥 ヒトメモ`
  （brief-viewerはタブに入れない＝引退方向。最下部に小さく「その他」リンク群として残してよい）
- **右メインエリア**：iframe。**タブごとにiframeを保持**（初回クリックで生成、以後はdisplay切替で
  即時切替・状態保持。全部を最初から読み込まない＝遅延生成）
- **上部ミニヘッダ**（メインエリア右上に小さく）：現在タブ名／「⟳ 再読込」（そのiframeのみreload）／
  「↗ 別タブで開く」（同URLをtarget=_blank）
- デザインは憲章準拠：静か・余白・最大3色。モバイルはサイドバーを上部の横スクロールタブに切替。

## 2. GDriveログインの制約対応【重要】

GoogleのOAuthはiframe内で実行できない（accounts.google.comがフレーム拒否）。対応：
- 各タブのミニヘッダに常設する「↗ 別タブで開く」で本体ページを開いてログインしてもらう
  （トークンはlocalStorage共有なので、戻ってiframeを⟳すれば接続済みになる）
- シェル側に1行ヘルプ：「Googleログインは『↗別タブで開く』から行ってください（ログイン後⟳）」

## 3. 「🏠 今日」タブ（シェル内蔵の初期ビュー）

シェル自身が描画する1枚（iframeではない）。朝はこのタブだけで完結させる。

構成（上から）：
1. **クイック追加バー**：1行入力＋追加ボタン。入力してEnterで**今日のShotタスクを作成**
   （shot-task-os-v1 へ直接書き込み。**実装前に shot-task-os の addTask 相当の項目構成を確認し、
   完全に同じフィールドで書くこと**。id生成は genUid 方式）
2. **今日のBrief（要点）**：localStorage['aix_draft_latest'] のmarkdownを描画
   （オブジェクト/文字列/JSON文字列の3形式対応は 1day の getAixDraft と同等の判定を実装。
   長いので既定は「# 今日の予定」「# 今日の要点」までを表示し「全文を見る」で展開）
3. **今日のタスク**：shot-task-os-v1 から dueDate<=今日 かつ status!=done を一覧表示、
   行頭に**✓チェック**（クリックで status='done'・completedAt 記録。既存スキーマ厳守）。
   ソース色（Lecticaカテゴリは紫系タグ）
4. **今日のLectica**：aix_lectica_pending（日付が今日のもの）の実験名＋「Reflectタブで記録」リンク

データは読み込み時＋タブ表示のたびに再読込（他タブでの変更を反映）。
書き込みは 1（クイック追加）と 3（✓完了）の2つだけに限定する（スキーマ二重管理を最小化）。

## 4. 実装ルール

- 単一HTMLファイル完結・vanilla JS・依存ゼロ（憲章どおり）
- 各OSのlocalStorageキーを**読み取り**で使うのは今日タブのみ。**書き込み**は shot-task-os-v1 のみ
- タブ構成は先頭の const TABS 配列で定義（名前・アイコン・URL）。並び替えが1か所で済むように
- 選択中タブを localStorage（launcher_last_tab）に保存し、次回起動時に復元（既定は「今日」）

- 動作確認チェックリスト：タブ切替で状態保持／⟳で該当iframeのみreload／↗別タブ／
  クイック追加→Shotタブに反映／✓完了→Shot側もdone／briefの3形式表示／モバイル幅で横タブ化
- 既存の各OS直アクセスが無影響であること
