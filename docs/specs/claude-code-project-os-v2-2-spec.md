# 変更1：レイアウト（左寄り解消・文字拡大）
- コンテンツが画面左に寄り、右に大きな余白がある。**本文コンテナに max-width（880〜960px目安）
  ＋左右中央寄せ（margin auto）**を適用する（ホーム・詳細・取り込みページ共通）。
- 基本文字サイズを1〜2px上げる。特に：PJ名／核3行（ゴール・問い・一手）の本文は
  現状より明確に大きく（読み距離の遠いデスクトップで10秒で読めるサイズ感）。
- ラベル（「ゴール」「問い」等）と値のコントラストを整理（ラベルは小さく薄く、値を主役に）。
- モバイル（〜640px）は現行の調整を維持（今回の拡大はデスクトップ主対象。崩れないことのみ確認）。
- ついで：サイドバー「ホーム」の赤バッジ（通知件数）は警告色が強いので、
  中立色（グレー系）に変更（内容は現行どおり危険温度感＋分岐接近のみ）。

# 変更2：「見立て」4項目（簡潔に書ける・重くしない）
核3行（ゴール／現在の問い／次の一手）の下に、**見立てブロック**を追加する：
- **成功条件**（何が満たされたら成功か）
- **悪い未来**（このまま進むと何が起きうるか）
- **センターピン**（今この瞬間、全体を動かす一点はどこか）
- **注意点**（気をつけること）

## ルール【重さを戻さないための縛り】
- 各項目**1行**（入力欄は1行テキスト。長文化させない）。
- 核3行と同じ**クリックでインライン編集**（モーダル禁止）。
- 全項目任意。未設定は薄い「未設定」表示のみ（催促文言・警告色・カウント禁止）。
- 新規PJ作成時に要求しない（必須はPJ名のみ、を維持）。

## データ
- **成功条件・注意点は既存メタの successCriteria／注意論点 相当のフィールドを再利用**する
  （実コードのフィールド名を確認。既存データがあればそのまま表示される）。
  再利用に伴い、折りたたみ「詳細メタ」からこの2項目は昇格・重複表示しない
  （詳細メタに残るのは前提条件・論点メモ）。
- **悪い未来・センターピンは新規フィールド**を追加（badFuture / centerPin 等。createdAt不要、
  値のみ。JSONエクスポート/インポートに含める）。
- 更新履歴はムーブ化しない（見立ては上書きでよい。履歴が要るのは核の問い・一手のみ、を維持）。

## 表示
- **PJ詳細**：核3行の直下に見立て4項目（1行ずつ）。
- **ホームのPJカード**：センターピンのみ、設定済みの場合だけ1行追加表示
  （カードの軽さを守るため他3項目はカードに出さない）。
- **壁打ちコンテキスト（単体版）**：設定済みの見立て項目を1行ずつ含める。
  400字制限は維持——超える場合は既存ルール（ムーブ件数の自動削減）で調整し、
  それでも超えるならセンターピンのみ残して他の見立ては省く。
  横断版は現行のまま（見立ては含めない・800字維持）。
