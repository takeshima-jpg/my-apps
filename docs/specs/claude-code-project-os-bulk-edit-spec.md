## 背景
PJ詳細の折りたたみ内にある「旧イベント一覧」「旧分岐一覧」（13列シートから取り込んだ
events / forks の過去データ）が、削除・完了とも1件ずつしか操作できず、整理に手間がかかる。
複数選択して一括で削除／完了できるようにする。

## 変更：一括操作モード
- 旧イベント一覧・旧分岐一覧（詳細の折りたたみ内）の各セクションに「選択」トグルを追加。
- 選択モードにすると各行にチェックボックスが出る。複数選択→下部（またはセクション上部）に
  一括操作バーを表示：
  - **一括削除**（確認ダイアログを1回・件数を明示。例「3件を削除しますか？」）
  - **一括完了**（完了状態のある項目＝分岐等に。イベントに「完了」概念が無ければ削除のみでよい・
    実コードを確認して適切な操作を出す）
- 「すべて選択 / 選択解除」も置く（大量整理用）。
- 一括操作後は一覧・件数・関連表示（カード等）を即時同期。

## データ
- 対象は既存の events / forks（旧データ）。moves（v2の新データ）は今回対象外
  （moves側は既にタイムラインで×削除できるため）。
- 削除は該当配列からの除去。分岐(forks)を削除する場合、moves側に同IDの分岐ムーブが
  連動している可能性を確認し、あれば連動削除（v2.1の「分岐はforksに同ID二重書き込み」の逆操作）。
- localStorage pos_v4 のキー・スキーマは変更しない。

## 検証
- 構文検証（node --check / esbuild）
- 選択モードでチェックボックスが出る／複数選択→一括削除で確認ダイアログ→削除実行
- すべて選択→一括削除が動く
- 一括完了（対象がある場合）が動く
- forks削除時にmoves側の同ID分岐も連動削除される（該当あれば）
- 削除後に一覧・件数・カード表示が同期／リロード後維持
- moves（新タイムライン）側は影響を受けない
- モバイル375pxで崩れない・コンソールエラーなし
