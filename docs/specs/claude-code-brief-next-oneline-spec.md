## §2 直すところ（`brief-viewer/index.html` の `lectinCardHTML()`・771 付近）
- `kind` が明日の予告のとき：
  - 開いたり閉じたりするカードにしない。見出し「✦ 明日の予告」（今の見出しと同じ小さな文字）と、その横か下に1行の文だけを出す。中身（お題・力・広がり方・示唆・合図・やり方を見る・なぜ今）は出さない
  - 18:00 の切り替えはやめる（時刻にかかわらず1行だけ）
  - 1行の文：
    1. `cardLine` が空でない文字列なら、それをそのまま
    2. 無ければ組み立てる：`{M/D（曜）}：{題名}（{実験ID}）× {関連の実験の題名}（{関連の実験ID}）——{nextScene の「→」より前}`
       - 日付は `date` から（今の見出しの日付と同じ書き方）
       - 題名は `title` か `selectedExperimentTitle`、実験ID は `experimentId` か `selectedExperimentId`（依頼書8と同じ読み替え）
       - 関連の実験（`relatedExperimentTitle`・`relatedExperimentId`）が無ければ「× …」ごと出さない。片方だけなら、ある方だけ（ID が無ければカッコごと出さない）
       - `nextScene` が無ければ「——…」ごと出さない。「→」が無ければ全文。前後の空白は落とす
       - 題名も実験ID も無ければ、カードを出さない（今と同じ）
  - 長い1行は折り返す（切らない・「…」で省略しない）。スマホ幅で横にはみ出さない
  - 日付が今日より前なら、今と同じく薄く出す（`bv-lectin-past`）
  - 省略の日（`skipped`）の1行の帯は今のまま
  - 文字は今の `_lxEsc` でエスケープする
- 「✦ 今日の実験」のカードは今のまま（いつも開いていて、力・広がり方・示唆・合図・やり方を見る）
