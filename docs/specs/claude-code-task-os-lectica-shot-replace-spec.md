# Claude Code 実装依頼書：autoGenLecticaShot() — 参謀提案による差し替え対応

作成日：2026-07-19
対象：repoの `task-os/index.html` の autoGenLecticaShot() および参謀提案の取り込み処理。
作業前に `git pull`。本仕様書は docs/specs/ に置いてから実装する。

## 問題
当日のLectica Shotに対する冪等ガード（既に存在すれば何もしない）が強すぎる。
ランダム生成が先に走った場合、後から取り込まれる参謀提案
（aix_lectica_pending・今日の日付）が反映されず、ランダム実験のまま残る。

## 修正内容
参謀提案の取り込み時に、次の条件を**すべて**満たす場合に限り、
当日のLectica Shot 1件を参謀提案の内容に**差し替える**：
1. 有効な参謀提案が存在する（aix_lectica_pending に今日の日付の提案がある）
2. 当日のLectica Shotが存在し、それが**ランダム生成由来**である
   （＝sanboShot無しで作られたもの。由来の判定に使える既存フラグ/フィールドを
   実コードで確認し、無ければ生成時に由来フラグを付与する形で対応。報告に明記）
3. そのShotが**未完了**である

### 差し替えない条件【厳守】
- 手動追加されたShot（自動生成でないもの）は差し替えない
- 完了済み（status='done' 等）のShotは差し替えない（実行済みの実験を上書きしない）
- 既に参謀提案由来のShotが当日分として存在する場合も差し替えない（重複反映防止）

### 差し替えの動作
- 対象Shotのタイトル・実験内容等を参謀提案の内容で更新し、由来を参謀提案（sanbo由来）として
  マークする（以降の再取り込みで二重差し替えが起きないように）
- 差し替え後も冪等：同じ参謀提案を再度取り込んでも変化しない
- 参謀提案が先に取り込まれた場合の従来動作（ランダム生成をスキップ）は変更しない

## 検証
- 構文検証（node --check / esbuild）
- ランダム生成が先→参謀提案取り込み→当日Shotが参謀提案の内容に差し替わる
- 差し替え後に再取り込みしても変化しない（冪等）
- 当日Shotを完了済みにした後に参謀提案を取り込んでも差し替わらない
- 手動追加したShotは差し替え対象にならない
- 参謀提案が先の場合、従来どおりランダム生成が走らない
- リロード後維持・コンソールエラーなし

## コミット
「task-os: autoGenLecticaShot — ランダム生成由来かつ未完了の当日Lectica Shotに限り、
後着の参謀提案（aix_lectica_pending）で差し替え。手動・完了済み・参謀由来は差し替えず冪等維持」

## 報告
変更ファイル／由来判定の実装（既存フラグか新規付与か）／差し替えロジックの挿入箇所／
テスト結果。実装を止める場合のみ質問を1つ。
