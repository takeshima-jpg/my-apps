## 背景（なぜ）

- 振り返りを取り込むたびに、【振り返り】の「問い」「次の実験」の行が全部そのまま探求ボードの候補になる（`tkMigrate`・2716行付近。1回に問い3・実験3）。後から細かい・ずれたものを一気に終わらせていて、完了した実験58本に学びが1本も残っていない
- 本人決定：振り返り1回から候補にするのは**問い0〜1・実験0〜1**。取り込む問いには**テーマを必ず付ける**（または「テーマなし」を明示）
- 半期・四半期の周期だけだと在り方の問いを忘れて動くので、**週と月に1タップで思い出す**仕組みを入れる。置き場所は Task OS の HOME（本人決定 11/2・B）。答えは Reflect の記録として残す

## 1. 振り返りの問い・実験を「下書き」に（Reflect OS）

**作り方**
- `tkMigrate` が新しいログから問い・実験を作るとき、`status:'draft'`（問い・実験とも新しい状態「下書き」）で作る。`sourceCk` の冪等はそのまま
- **例外：受信箱から入った振り返りのうち、受信箱の1件の `source` に「リフレクト見直し」を含むもの**は、今までどおり候補（candidate）で作る（担当が置くのは本人がチャットで選んで OK したものだけのため。本人決定 11/2）
  - `inboxApply(block, links, item)` で `item.source` を `reflectImportText` へ渡し、作ったログに `importSource`（例「リフレクト見直し」）を残す。`tkMigrate` はそれを見て分ける
- それ以外の受信箱分、画面の「⬇ 取り込む」、起動時の移行で新しく生まれる分は下書き
- 既にある候補・重点・実験中などは変えない（さかのぼらない）
- 下書きは探求ボードの候補一覧・重点・実験中・`reflect_focus_v1` には出さない。上限の数にも入れない

**選ぶ画面**
- 探求ボードの上に、下書きがある間だけ「振り返りから選ぶ」の欄（件数バッジ・「0件」は出さない）
- 振り返りのログ1件ごとにまとめて表示：そのログの日付・題名、下書きの問い（最大3）・実験（最大3）
- 選べるのは**問い0〜1・実験0〜1**（ラジオ。問い・実験それぞれ「選ばない」も既定で1つ）
- 問いを選んだら、テーマを選ぶ欄が出る：外していないテーマ（`detached` でない・完了でない）＋「テーマなし」。**どちらかを選ばないと確定できない**（`テーマなし` は `themeIds:[]`・`noTheme:true`）
- 実験を選んだら、つなぐ問い（いま選んだ問い／既存の候補・重点の問い／つながない）を選べる（任意）
- 「確定」で：選んだ問い・実験を `candidate` に、選ばなかったそのログの下書きは `status:'draft_dropped'`（消さない・一覧には出さない）。1回の確定で終わり
- 「あとで」：そのまま残す（次に開いたときも出る）
- ボタンは 44px 以上、選択肢は少なく（ヒック）、書かなくても選ぶだけで終わる形

## 2. 週の2択（Task OS HOME・答えは Reflect の記録へ）

**出す時期**：その週（月曜はじまり）の**金・土・日**だけ。月曜〜木曜は出さない（月曜は Brief の「今週の構え」があるため）。その週に答えたら消える。答えないまま月曜になったら、その週の分は出さない（持ち越さない・催促しない）

**中身**：
- 見出し1行「この週、この構えを使う場面はあったか？」
- 重点の問い（`reflect_focus_v1.focusQuestions`・最大3）を1行ずつ、各行に「あった」「なかった」の2ボタン
- 全部答えたらカードごと消える。途中まででも答えた分は保存
- 重点の問いが0本なら出さない。バッジ・赤・件数表示なし

## 3. 月の1問（Task OS HOME）

**出す時期**：毎月1〜7日。前月分に答えたら消える。8日を過ぎたら出さない（持ち越さない）

**中身**：「先月いちばん動いたテーマは？」と、テーマのボタン（外していない・完了でないテーマ。多くても5つまで並べ、超えたら優先度順の上位5）＋「どれでもない」

## 4. 記録の置き場（両OS）

- Reflect が持つ新しいキー `reflect_stance_v1`（localStorage・Task OS が書く）：
  ```
  { weeks:  [{ week:'2026-W45', answers:[{questionId, title, used:true|false, at}] }],
    months: [{ month:'2026-10', themeId|null, themeTitle, at }] }
  ```
  - 同じ週・同じ問いの答え直しは上書き。月も上書き
- テーマの一覧を Task OS が読めるよう、`reflect_focus_v1` に `themes:[{id,title,priority}]`（外していない・完了でないもの）を足す（`tkMirrorFocus`。Task OS が読む形式なので両OS同時に変更＝CLAUDE.md の注意どおり）
- Task OS の全OSバックアップ（`collectAllOSData`）に `reflectStance: jGet('reflect_stance_v1')` を足す。復元側にも足す
- CLAUDE.md の「データ契約」に `reflect_stance_v1` を追記
- Reflect OS 側：問いの詳細に「場面があった週：n／答えた週 m」を1行（薄く。答えが無ければ出さない）。四半期の棚卸しで数えるため

## 5. 受入条件（playwright）

1. 画面の「⬇ 取り込む」で問い3・実験3の【振り返り】→ 探求ボードの候補は増えず、「振り返りから選ぶ」に1件
2. 問いを1つ選んでテーマ未選択 → 確定できない。「テーマなし」で確定できる。確定後、選んだ問い・実験だけ候補、残りは `draft_dropped`、欄が消える
3. 受信箱 `source:"リフレクト見直し"` の【振り返り】→ 下書きを通らず候補。`source:"VISION見直し"` → 下書き
4. 既存の候補・重点はそのまま。下書きは上限の数・`reflect_focus_v1` に入らない
5. Task OS HOME：月〜木は週の2択が出ない、金〜日に出る。3問とも答えると消え、`reflect_stance_v1` に1週分。同じ週に再び出ない
6. 月の1問：1〜7日に出て、選ぶと消え、`months` に1件。8日以降は出ない
7. バックアップに `reflectStance` が出る。復元で戻る
8. Reflect の問いの詳細に「場面があった週」が出る（答えがある問いだけ）
9. バッジ・赤・「0件」表示なし。ボタン44px以上・375px・コンソールエラー0・構文検証OK・task-os の BUILD_VER・両OSの SW 版上げ
